🚀 What is iDash?

iDash (Intelligent Distributed Asset Scanning Hub) is a web-based presentation and operations platform designed to bridge enterprise asset databases with field operations — RFID scanning, label printing, automated reporting, and multi-site inventory reconciliation.

Originally built for large-scale enterprise deployments, iDash acts as a unified hub connecting fixed and mobile RFID readers, label printers, and back-office databases without requiring changes to existing database schemas or adding heavy middleware.

Connected to your data. Optimized for your team. Zero runtime lock-in.

🏗️ Architecture

iDash is a presentation and operations layer — not a database platform. It connects to your existing data infrastructure and provides the tools your teams need to do their work.

Key Design Decisions

  • No JavaScript frameworks — vanilla JS keeps the stack simple and fast without build tooling
  • No ORM — direct SQL via SqlConnection for full query control and performance
  • No external print service — BarTender SDK runs in-process; labels print directly
  • Backend-agnostic — connects to any SQL Server database schema
  • Self-contained — docs, templates, tools, and config all ship inside the app directory

🔒 Security

  • Tile-based permissions — every page is gated by a tile key; users only see what they're authorized to access
  • Site-level data isolation — dynamic SQL WHERE clauses restrict data to assigned facilities
  • Role hierarchy — Admin, User, and custom roles with granular tile and site assignments
  • Session-based auth — supports local auth or integration with external identity providers
  • Section 508 / WCAG 2.0 AA — keyboard navigation, screen readers, focus indicators, color contrast

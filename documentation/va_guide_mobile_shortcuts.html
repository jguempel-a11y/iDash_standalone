2. How to Create Home Screen Shortcuts on Mobile Readers

To give field technicians instant 1-tap access without typing URLs or searching through bookmark menus, install home screen shortcuts directly onto the Zebra TC53 / TC58 handhelds:

Method A: Google Chrome / Microsoft Edge on Zebra Android (Quickest)

  1. On the Zebra handheld, open Chrome or Edge and navigate to the desired scanning tool URL (e.g. https://<your-server>/idash/va_inventory.aspx).
  2. Tap the three vertical dots menu (⋮) in the top-right corner of the browser.
  3. Select “Add to Home screen” (or “Install app”).
  4. Edit the name to a short, recognizable title:
    • VA Inventory (for va_inventory.aspx)
    • ENNX Scan (for va_ennx_live_scan.aspx)
    • EIL Reconcile (for va_eil_live_scan.aspx)
    • Universal ENNX (for va_universal_ennx.aspx)
  5. Tap Add. The official iDash RFID badge icon will appear directly on the Android home screen launcher.
💡 Field Tip: Create all 4 shortcuts and place them inside a dedicated “iDash Scanning” home screen folder on the handheld for seamless access during shifts.

Method B: Zebra Enterprise Browser / StageNow (Locked Down Kiosk)

If your facility utilizes Zebra Enterprise Browser or StageNow in dedicated kiosk mode, configure the shortcuts via Config.xml:

<!-- Zebra Enterprise Browser Config.xml --> <Configuration> <Applications> <Application> <General> <StartPage value="https://laptop-e74ckmo5.tail2fc4c5.ts.net/idash/va_inventory.aspx"/> </General> <Navigation> <NavDelay value="0"/> <HideNavBar value="1"/> </Navigation> </Application> </Applications> </Configuration>

3. Security & Deep-Linking Single Sign-On Workflow

In accordance with NIST SP 800-53 Access Control guidelines and our commercial security review, direct URL access to scanning tools is strictly gated. However, to ensure frictionless user experience, iDash utilizes Safe ReturnUrl Deep-Linking:

→

Immediately lands directly on the scanner!

Why This Matters for Field Techs

  • Active Session (0 Extra Taps): If the technician is already signed in on the handheld, tapping the shortcut opens the scanner immediately without any login prompts.
  • Expired Session (Seamless Return): If the session expired overnight or between shifts, the tech enters their PIN or password, and the system automatically routes them straight back to the scanner they requested — never dumping them on the main dashboard to search for their tile again.
  • Open Redirect Protection: The `returnUrl` validator strictly verifies that destinations are internal relative paths, preventing open-redirect security vulnerabilities.

4. DataWedge Profile Download & Handheld Setup

iDash provides a pre-tuned Zebra DataWedge profile tailored specifically for the Zebra TC53 / TC58 mobile computer paired with the RFD40 RFID Sled. It configures hardware RFID triggers, duplicate tag filtering (100ms suppression), and Basic Data Formatting (BDF) with an automatic ENTER key suffix so scans immediately register in the web forms without requiring manual keypad taps.

📥 Download DataWedge Profile Files

These files are hosted on your iDash server and can be downloaded directly from any handheld reader or PC:

🗄 Download datawedge.db (Direct Database) 📦 Download Zebra_DataWedge_RFD40_Profile.zip (Full Package) 📂 Browse Downloads Center →
⚠️ CRITICAL PREREQUISITE: Install Zebra Enterprise Browser First!
Before importing the DataWedge profile, you MUST install Zebra Enterprise Browser on the handheld from the Google Play Store (package: com.zebra.mdna.enterprisebrowser).

Why this is required: When DataWedge imports the database, it searches the Android system for the associated app package. If Zebra Enterprise Browser is not installed yet, DataWedge will fail to link the profile, and the Associated Apps section in iDash_Enterprise_Browser will be blank!

Full Step-by-Step Reader Setup Procedure

Step 1: Install Zebra Enterprise Browser from Google Play Store

  1. Connect the Zebra TC53 / TC53E / TC58 reader to Wi-Fi.
  2. Open the Google Play Store on the handheld.
  3. Search for Zebra Enterprise Browser.
  4. Tap Install. Once installed, do not configure it yet — proceed to Step 2.

Step 2: Copy the DataWedge Profile via USB from PC

  1. On your workstation, download the profile from iDash:
    📦 Download Zebra_DataWedge_RFD40_Profile.zip or extract the com.symbol.datawedge folder from downloads/Software/.
  2. Connect the Zebra handheld (e.g. TC53E) to your PC using a USB-C cable.
  3. On the handheld screen, swipe down the notification shade → tap Charging this device via USB → change USB preference to File Transfer (MTP).
  4. On your PC, open File Explorer and navigate to:
    This PC\TC53E\Internal shared storage\Android\data\
    (Replace TC53E with your specific handheld device name if different).
  5. Copy the entire com.symbol.datawedge folder (which contains files\datawedge.db) into this Android\data\ folder.
    ✔ The resulting path on the reader will be: This PC\TC53E\Internal shared storage\Android\data\com.symbol.datawedge\files\datawedge.db

Step 3: Import the Profile into DataWedge

  1. On the handheld reader, open the Android app launcher and tap DataWedge.
  2. Tap the three vertical dots (⋮) in the upper right corner of the screen.
  3. Select Settings.
  4. Select Restore (or Import database).
  5. Browse and select datawedge.db (located in device storage under Android/data/com.symbol.datawedge/files/ or Download/).
  6. Tap OK. DataWedge will reload and confirm: "Database restored successfully".

Step 4: Verify Profile & Associated App Link

  1. In DataWedge, look for the profile named iDash_Enterprise_Browser.
  2. Tap into iDash_Enterprise_Browser.
  3. Check Associated apps: You should see *.com.zebra.mdna.enterprisebrowser (or com.symbol.enterprisebrowser) populated.
  4. Confirm RFID Input is checked/enabled (RFD40 trigger active).
  5. Confirm Keystroke output is enabled with Basic data formatting (BDF) → Send ENTER key checked.

RFD40 Hardware Sled Ergonomics

  • Bluetooth Sled Pairing: Ensure the 123RFID Mobile or Zebra RFID app reports "Connected to RFD40" before launching the web scanner.
  • Keystroke Output & ENTER Suffix: The profile ensures Keystroke Output is enabled with a carriage return (\n / hex 0x0A), triggering instant $O(1)$ client-side tag matching.
  • Power Range Setting:
    • Small Offices & Exam Rooms: Set RF power to 15–18 dBm to prevent signal bleed through drywall.
    • Warehouse / Open Bay Storage: Set RF power to 27–30 dBm for maximum read range (15–25 feet).

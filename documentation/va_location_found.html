Module Purpose

This module provides a dedicated interface for Location Found within the AssetWorx iDash ecosystem. It enables personnel to interact securely with underlying data processes.

Technical Operation

The system primarily renders the user interface through the web endpoint va_location_found.aspx. It securely queries the AssetWorx SQL database using inline ADO.NET connections (SqlConnection), leveraging configured network credentials to safely retrieve or update asset tracking records.

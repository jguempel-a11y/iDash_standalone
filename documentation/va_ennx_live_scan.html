📤 ENNX Live Scan (Mobile RFID Optimized)

✔ Direct Database Commit ✉ Email Export ⚡ Mobile RFID Optimized (v2.0) 👤 Operator Auth Synchronized

The ENNX Live Scan module is a high-speed, mobile-optimized asset scanning and inventory reconciliation tool designed for Zebra mobile RFID handhelds and web workstations. It captures location barcodes and asset tags in real time, organizes them into government-ready ENNX structures, and directly commits the updated inventory locations and timestamps to the AssetWorx database with an automated audit log.

🔍 Collected EILs Filter Engine & Quick-Select Chips (09/17/2026)

Previously, filtering by EIL required scrolling through a massive dropdown containing every registered facility EIL (over 4,300+ distinct EILs for Station 517 alone), which was slow and impractical on mobile RFID handhelds.

The EIL filter has been moved to the top of the Scan Stream & Reconciliation card and upgraded with a responsive dual-mode selector:

  • Collected in Active Scan: As assets are scanned or restored from session storage, their EILs (dbo.asset.text8) are resolved and populated into a targeted dropdown and interactive pill chips showing asset counts (e.g., 782 (1), 78YM (1), All (3)).
  • Quick Search / Autocomplete: A search box with an integrated datalist allows typing or selecting any station EIL directly without endless scrolling.
  • Bi-directional Filtering:
    • Post-Scan Reconciliation: Tapping an EIL chip instantly filters the Stream Table and the Live ENNX Preview / Export to only the assets belonging to that specific EIL.
    • Pre-Scan Enforcement: When scanning with an active EIL filter, any incoming asset belonging to a different EIL is automatically flagged as an Ignored mismatch row with an audible/visual notice, preventing accidental mixed-EIL inventory capture.
  • Live EIL Badges: Every scanned asset in the reconciliation feed displays an inline blue pill badge with its resolved EIL code for quick visual verification.

Field Sweep User Workflow

1
Verify Operator & Site: Confirm your technician name is displayed in the top bar (e.g., 👤 Gary Moe). Your assigned VA facility is auto-selected and locked.
2
Scan a Location Barcode: Pull the scanner trigger or scan a room barcode starting with SP (e.g., SP009-BD. 8A). The room is highlighted in blue and set as the active location.
3
Sweep Equipment Asset Tags: Pull the RFID trigger or scan asset barcodes. All valid tags under the active location are highlighted in green, de-duplicated in memory, and formatted into the live ENNX preview.
4
Move to Next Location: Scanning another SP room barcode automatically begins a new location block. Or, click ↦ Force Location if the barcode format is non-standard.
5
Commit Scans to Database: Tap 💾 Commit Scans to Database. All scanned assets are immediately updated with their new room location (text6) and current inventory timestamp. An audit row is logged with the session payload.
6
Optional: Email ENNX File: Tap ✉ Email ENNX File to dispatch the formatted ENNX text file directly to designated inventory administrators.

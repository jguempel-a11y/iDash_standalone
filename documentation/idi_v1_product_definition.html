2. Version 1.0 — Locked Commercial Feature Scope

The following represents the locked release boundary for iDash V1.0. Features within this boundary are production-tested, hardened, and supported. Items outside this boundary are formally assigned to the post-V1 roadmap.

💻 Browser & User Experience

  • Zero-footprint web application for desktop, rugged tablet, and handheld browsers.
  • Full compatibility with Chrome and Zebra Enterprise Browser.
  • Single URL navigation with role-appropriate views (Biomed, Logistics, Warehouse, Admin).
  • Multi-site and site-scoped access control with granular facility partitioning.
  • Dark mode / light mode theme support with responsive high-density data tables.

📡 Handheld Inventory & Locating

  • Real-time room inventory sweep engine executing at 30–50 tags/second.
  • Instant reconciliation: Green Found, Red Misplaced, Yellow Missing, Gray Unregistered.
  • Targeted RFID locating with audible & visual "Geiger-counter" proximity signal strength.
  • Tag Team Scan offline caching engine with batch synchronization upon reconnection.
  • Automatic tag validation against configured EPC formats and filter rules.

🏷 Field Tagging & Label Printing

  • Barcode scanning to look up equipment, verify existing records, and bind RFID tags.
  • Authorized correction of selected asset fields through controlled, auditable workflows.
  • Browser-driven direct ZPL label printing and RFID tag encoding with print preview.
  • Multi-printer support for desktop and mobile Zebra RFID printers (ZT411, ZD621R, etc.).
  • Batch print queue and bulk tagging project workflows.

📊 Reporting & Operational Analytics

  • Sub-second multi-criteria asset search across serial, EE, CMR, model, and location.
  • Configurable table columns, persistent user filters, and saved views.
  • Comprehensive inventory audit reports, CMR variance statistics, and Excel export.
  • Read-only analytical SQL reporting queries with transactional safety.
  • Discrepancy dashboards highlighting missing, expired, and misplaced capital assets.

🗺 Fixed RFID & Location Intelligence

  • Direct integration with fixed UHF RFID readers (Zebra FX9600, FX7500).
  • Timestamped asset movement and transit events captured from choke-points and doorways.
  • Interactive 2D floorplan visualization and antenna zone location mapping.
  • Comprehensive location history audit trail for high-value equipment finding and chain-of-custody.
  • Real-time antenna diagnostic telemetry and heartbeat monitoring.

🔐 Security, Administration & DevOps

  • On-premises IIS / ASP.NET server deployment running on Windows Server with SQL Server.
  • Role-based access control (RBAC), fail-closed authorization, and persistent security audit log.
  • Integrated deployment and system diagnostics wizard (deploy_idash.aspx).
  • Complete Software Bill of Materials (SBOM) and third-party attribution register.
  • Documented installation, database backup, restore, upgrade, and rollback procedures.

3. Explicitly Outside V1.0 — Post-V1 Roadmap

To guarantee commercial delivery and support stability, the following capabilities are explicitly deferred to subsequent version releases:

🚫 Deferred Architecture Scope
  • Cloud / Multi-Tenant SaaS Hosting: V1 remains strictly on-premises and air-gapped intranet certified.
  • Native App Store Binaries: V1 standardizes on high-performance browser PWA and Zebra Enterprise Browser.
  • Active Beacon Hardware: V1 is purpose-engineered for passive EPC Gen2 UHF RFID technology.
🚫 Deferred Integration Scope
  • Unattended Host System Writes: Automated write-backs to external host systems without operator confirmation.
  • Direct Pre-Built ERP Connectors: Direct Nuvolo, ServiceNow, or Oracle adapters (assigned to the Connector module roadmap).
  • National Data Lake Aggregation: Cross-VISN central aggregation beyond the facility-level database clustering supported in V1.

Core Pricing Philosophy

iDash utilizes a per-facility site license model rather than restrictive per-user seats. This encourages broad facility-wide adoption across Biomed, Logistics, Warehouse, and Quality teams without administrative friction, while monetizing enterprise scale, advanced modules, and recurring support.

📖 iDash Module Overview

Quick-reference guide to every module in the iDash portal. Each entry lists the module name as it appears on the dashboard, the source file, a short description, and the access level required. For in-depth documentation on any module, see its dedicated doc page linked from the Documentation Hub.

All Users = Visible based on tile permissions Login Required = Requires admin authentication Admin Only = Restricted to system administrators

📊 Reports

Dashboards and data exports for management review, auditor submission, and operational visibility.

ModuleSource FileDescriptionAccess
Asset Overview & Analytics va_asset_stats.aspx Full asset dashboard — overview counts, data quality checks, items not in use, and site-wide analytics with chart visualizations. Four consolidated tabs: Overview, Data Quality, Not In Use, Analytics. All Users
Tagging Progress & Activity va_tag_stats.aspx Tagging progress by site and employee. KPI summaries, tag type breakdowns, and employee performance metrics with Excel export. All Users
Room & Equipment List Progress va_cmr_stats.aspx Total assigned assets and last inventory dates across all rooms (CMRs) and equipment lists (EILs). Includes CMR accountability tracking and multi-CMR filtering. All Users
Find Assets by Room va_assets_by_location.aspx Assets grouped by last known room/location with time since last scan. All Users
Room Directory va_location_list.aspx Browse all registered rooms and locations with current asset counts. All Users
Tagging Activity Summary va_tag_audit_report.aspx Review tagging activity by date range and tag type. Filters on DateModified using ASP.NET GridView binding. Used by auditors and management for progress confirmation. All Users
Overdue Inventory Report va_report_inventoried.aspx Assets not inventoried recently, grouped by overdue duration bands. All Users
Inventory Export Files (ENNX) va_ennx.aspx Generate and download ENNX-format inventory export files for VA submission. Supports multi-day date ranges, site-specific filtering, and OIT/No-Data preview. All Users
Daily Report Automation va_report_automation.aspx Configure the automated 7PM extraction of daily ENNX & Excel reports for sites with new scanning activity. All Users
Past Inventory Sessions ennxhistory.aspx Review previous inventory scan sessions by user and date. Download or email batch reports. All Users
Asset Values va_tag_stats.aspx View and export asset valuations — tagged Not In Use value totals and full portfolio value by site. Accessible only after admin login. Login Required

🔍 Search & Lookup

Research tools for locating specific assets, rooms, tags, and scan history.

ModuleSource FileDescriptionAccess
Search Assets & Records va_data_research.aspx Global search by asset name, location, EIL number, or tag type. Advanced querying system for viewing large datasets with filtering and export. All Users
Asset History Lookup va_previous_location.aspx Look up an asset number or EIL to see its last scan location and full location history. All Users

📱 Scanning & Tools

Live scanning dashboards, inventory tools, ENNX generation, and print template management.

ModuleSource FileDescriptionAccess
Site Location Maps va_site_maps.aspx Track progress through facility maps to ensure no rooms are missed during tagging sweeps. All Users
Tag Team Scan va_tagteam_scan.aspx Team scanning dashboard with ENNX integration and custom template printing. The primary field scanning interface. All Users
VA Site Inventory va_inventory.aspx Rapid location sweep interface. Pre-loads room assets, verifies found items, and automatically moves misplaced assets to the current scanned location. All Users
ENNX Live Scan va_ennx_live_scan.aspx Live asset scanning tool for generating ENNX data. Requires site selection and database connection. Sessions are saved to EnnxLiveSession table. All Users
Universal ENNX Creator va_universal_ennx.aspx Build and download an ENNX file from any scanner — barcode, RFID, or both. No site selection or database required. All Users
EIL Live Scan & Reconciliation va_eil_live_scan.aspx Load an EIL parts list and reconcile against live scanning. Generates ENNX payloads during the scan. All Users
Print Template Mappings va_print_mapping.aspx Bind device scanning Tag Types to custom AssetWorx print templates for automatic label routing. All Users

🔒 Admin & Database Tools

Restricted tools for database maintenance, server configuration, data synchronization, and system monitoring. Requires admin login.

⚠ Access Restriction: All modules in this section require admin authentication via the Admin & Database Tools login on the main iDash portal. Some tools perform destructive write operations.
ModuleSource FileDescriptionAccess
Site Configuration va_site_config.aspx New VISN server setup wizard. Update DB connection string, API credentials, SMTP / email settings (including recipients and report automation), and run the one-time company SQL — all from one page. Email configuration was consolidated here from the former standalone Email Config page. Login Required
Field Server Sync va_field_sync.aspx Restore a field server .bak to staging, then merge updated asset data into the central database for executive reporting. Supports nightly automation. Login Required
Manual DB Update va_dbupdate.aspx Upload data files (.csv / .xlsx) and SQL scripts to apply manual database updates. Executes MERGE and UPDATE batch scripts against the existing database. Login Required
Auto DB Update va_autodbupdate.aspx Folder watcher and scheduled database update processor. Monitors the autoload folder for incoming data files and runs SQL update scripts automatically. Login Required
SQL Upload va_sql_upload.aspx Upload and execute .sql scripts on the production database with multi-stage safety parsing and transactional rollback protection. Admin Only
Site Data Export & Import va_sitedata_export.aspx Export or import a site’s complete asset records using high-speed SqlBulkCopy staging table engine for data migration between iDash systems. Login Required
Excel Merge Tool va_excel.aspx Merge equipment files with site master sheets for bulk data reconciliation. Login Required
System Automations va_automated_reports.aspx Configure automated daily reporting emails, trigger testing, and event notifications. Login Required
System Logs & Automation History va_autodbupdate.aspx?view=logs View the DB update log, Field Sync log, and links to the full IIS & App log analyzer. Consolidated log viewing interface. Login Required
IIS & App Log Analyzer va_log_viewer.aspx Advanced web server log analysis — filter IIS logs by IP, URI, and status code. Auto-diagnoses common AssetWorx service errors from Serilog app logs. Login Required
Database Restore va_db_restore.aspx Restore the AssetWorx database from a .bak backup file. DANGER ZONE — overwrites the live production database. Admin Only
Support Request index.aspx (modal) Sends a support email directly to ID Integration Support (varfid_support@id-integration.com) with a CC to the submitter. The form collects the user’s name, email, phone number, and issue description. Subject is auto-populated as “Support Request from [site]” using the user’s assigned iDash site. Reply-To is set to the submitter so support can reply directly. Accessible via the Support Request pill in the user bar (upper-right, visible when logged in). Login Required
Supply Chain Bridge va_fhir_bridge.aspx Push supply chain data (assets & locations) from AssetWorx to VA VistA via AEMS/MERS SQL sync. Includes ENNX session loading, parsing, and 7-step push pipeline. Login Required
User Management va_user_management.aspx Create, edit, disable, and delete iDash portal user accounts. Control role-based access to tools, scanning, admin panel, and documentation. Admin Only

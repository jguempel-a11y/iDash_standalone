🚀 iDash Deployment & System Wizard

Autonomous 5-step installer, database schema engine, multi-site provisioning utility, and production validation certifier.

🚀 Launch Wizard ⌂ iDash Hub
Why was this wizard created?
Historically, deploying iDash required manual SQL scripts, SSMS table creation, manual IIS directory permission checking, and separate multi-site setup steps. The Deployment & System Wizard (deploy_idash.aspx) turns this into an autonomous, single-screen experience that guarantees 100% clean standalone operation with zero legacy AssetWorx or InfinID dependencies.

1⚙ The 5-Step Automated Pipeline

1

Host Environment & Prerequisites Check

✓ Automated Probes
Executes non-destructive real-time probes against the host system:

💻 IIS & ASP.NET 4.8

Verifies CLR version, worker process identity (IIS_IUSRS / AppPool), and application pool architecture.

📁 File Write Permissions

Ensures App_Data/, logs/, config/, and uploads/ have read/write access.

🗃 SQL Connectivity

Tests connection string reachability, SQL instance latency, and database credentials.

2

Database Schema Engine & Initializer

⚙ Standalone Schema
Inspects the target SQL database and compares it against the pure standalone iDash baseline:
  • 26 Clean Core Tables: Ensures v_asset, asset_inventory, company, locations, fixedreader, printjob, printtemplate, and printerrouting exist with exact modern schemas.
  • Zero Legacy Columns: Guarantees no orphaned AssetWorx or GPS tables remain.
  • One-Click Deployment / Upgrade: Automatically provisions missing tables, indexes, and optimized reporting views (v_asset_extended) safely without data loss.
3

Multi-Site Isolation & Facility Provisioning

🏢 Multi-Tenant
Configures strict tenant data isolation by provisioning site and station identifiers:
  • Lists all active facility stations (e.g., 517 Beckley, 512 Baltimore, 613 Martinsburg).
  • Allows instant one-click provisioning of new stations and facility names with cascade integrity.
  • Ensures scanner sessions, reader antenna observations, and ENNX exports strictly honor site filtering.
4

Admin & Security Setup

👤 RBAC & Auth
Manages the central administrator account (idashadmin) and sets up authentication parameters:
  • Cryptographic password update using PBKDF2 with SHA-256 and salted HMAC hash storage.
  • Sets default technical alert notification email address.
  • Enforces role-based access control (RBAC) across all administrative tools.
5

End-to-End Validation Suite & Production Certification

🎉 Verified Ready
Executes automated integration test probes simulating actual field usage:
  • Database Read/Write Probe: Validates transactional writes and rollbacks.
  • Unified Views: Queries v_asset and location hierarchy to ensure sub-millisecond query performance.
  • Scan API Endpoint: Simulates live handheld and fixed reader packet submission.
  • Certification Certificate: When 100% of probes pass, generates an on-screen verified certificate stamped with host name and UTC timestamp, complete with quick-launch buttons to the iDash Hub, Asset Master, and Fixed Reader Portal.

2🔗 Accessing the Wizard

The deployment wizard can be launched from multiple locations in iDash:

🌐 Direct URL

Navigate directly in your browser:
http://localhost:8181/deploy_idash.aspx

⌂ Main iDash Hub

Located under Admin Tools → 🚀 iDash Deployment & System Wizard, or search "deploy" in the Command Palette.

⚙ Site Configuration

Accessible from the sidebar navigation (🚀 Deployment & DB Wizard) or the Database panel in va_site_config.aspx.

📋 EIL Live Scan & Reconciliation (Mobile RFID Optimized)

✔ Direct Database Commit ✉ Email Export & Excel Report ⚡ Mobile RFID Optimized (v2.0) 👤 Operator Auth Synchronized

The EIL Live Scan & Reconciliation module is a high-speed, mobile-optimized asset accountability tool designed for Zebra mobile RFID handhelds and web workstations. It loads targeted Equipment Item Lists (EIL / CMR) into an interactive checklist, cross-references physical sweeps in real-time, compiles government-ready ENNX export structures, and directly commits updated inventory locations and timestamps to the iDash database.

EIL Field Sweep Workflow

1
Verify Operator & Site: Confirm your technician name is displayed in the top bar (e.g., 👤 Gary Moe). Your assigned VA facility is auto-selected and locked.
2
Load EIL / CMR Checklist: Type or select the targeted CMR from the EIL / CMR input and tap Load EIL. The checklist table populates with all assigned equipment and sets pending status.
3
Scan a Location Barcode: Pull the scanner trigger or scan a room barcode starting with SP (e.g., SP009-BD. 8A). The room is highlighted in blue and set as the active location.
4
Sweep Equipment Asset Tags: Pull the RFID trigger or scan asset barcodes. All matched tags turn green (Found) in the EIL checklist and populate with their new room location.
5
Commit Scans to Database: Tap 💾 Commit Scans to Database. All scanned assets are immediately updated with their new room location (text6) and current inventory timestamp. An audit row is logged with the session payload.
6
Email ENNX File & Report: Tap ✉ Email ENNX & Report to dispatch the formatted ENNX text file along with the full EIL reconciliation Excel report directly to inventory administrators.

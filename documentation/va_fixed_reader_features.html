📡 Live Feed & Tag Detection

The Live Feed page (va_fixed_reader_live.aspx) connects to the tag event stream via Server-Sent Events (SSE) and displays tag reads as they happen. No polling — data pushes to the browser immediately.

How It Works

  1. A fixed reader (e.g., Zebra FX9600) reads RFID tags via its antennas
  2. The CrossSiteTagObserver service processes the read and publishes it via MQTT
  3. The iDash SSE endpoint receives the MQTT message and streams it to connected browsers
  4. The live feed page renders the read instantly with status indicators (Seen, Moved, New, Watched, Cross-Site)

🎯 Asset Watch List & Export

The Watch List is a powerful tool for finding specific assets. Enter asset numbers and the system monitors every tag read, highlighting matches instantly.

Setting Up a Watch List

  1. Navigate to the Fixed Reader Live Feed page
  2. In the sidebar, find the Asset Watch List section
  3. Enter asset names or partial numbers (e.g., 613 EE11855, 400-12345)
  4. Click Watch to activate. The list persists across page refreshes via localStorage
  5. As assets are detected, they are marked as Found with the time and location

Exporting Found Assets

ActionDescription
Export Found to CSVDownloads a CSV file with: Asset Name, EPC, Status (Found/Not Found), Time Detected, Location/Antenna. Give this to a warehouse team to physically locate the assets.
Open in Asset MasterOpens Asset Master in a new tab with the found assets pre-filtered in the grid. Review full asset records (CMR, description, location, status) for all detected assets. A green banner shows the filter is active.
Tip: The Watch List supports partial matching. Entering EE1185 will match 613 EE11855, 613 EE11856, etc.

🔎 Missing Asset Report

Using the Report

  1. Navigate to the Fixed Reader Dashboard (va_fixed_reader.aspx)
  2. Scroll to the Missing Asset Report section and click the header to expand
  3. Select a time window: 30, 60, 90, 180, or 365 days
  4. The report loads showing all assets NOT observed by a fixed reader within that window
  5. Use the inline column filters to narrow results (e.g., filter by location or CMR)
  6. Click Export CSV to download the list for manual inventory verification
Why this matters: VA facilities are required to conduct periodic physical inventory of all assets. The Missing Asset Report tells you which assets still need manual verification after the fixed readers have automatically confirmed the rest. This dramatically reduces the scope of physical inventory.

🌐 Cross-Site Visitor Detection

When a fixed reader at one site detects an asset that belongs to a different site, the system handles it as a cross-site observation — the asset is not moved or reassigned.

ScenarioWhat Happens
Same-site asset readNormal processing: update observation data, create location history, update location assignment if reader has UpdateLocation enabled.
Cross-site asset readOnly lastobservedtime is stamped. No location history, no location assignment, no lastobservedlocation change. The asset stays in its home site.
Important: Cross-site assets appear in the live feed labeled with their home site name so operators know the asset is a visitor, not a local asset.

📈 Reader Coverage Analytics

Understanding your reader coverage helps justify reader placement decisions and identify gaps.

MetricDescriptionGoal
Both (Fixed + Mobile)Assets verified by both fixed readers AND handheld scansHighest confidence
Fixed OnlyAssets verified only by fixed readers (never hand-scanned)Automated verification
Mobile OnlyAssets verified only by handheld scans (not in reader range)Manual coverage
Not ReadAssets never verified by either methodMinimize this
Best Practice: Use the "Not Read" count to identify areas where readers should be added or where antenna positioning should be adjusted. A coverage percentage above 85% indicates strong reader placement.

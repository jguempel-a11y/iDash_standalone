📱 Guide: Zebra TC53 Scanner Setup

Standard operating procedure for setting up the Zebra TC53 / TC58 mobile computer paired with the RFD40 RFID Sled to run the iDash (Intelligent Distributed Asset Scanning Hub) web platform in Google Chrome (with Zebra Enterprise Browser installed for hardware support and DataWedge).

Browser & Platform Architecture: Daily scanning in iDash is conducted using Google Chrome (or 1-tap home screen web shortcuts). However, Zebra Enterprise Browser (EB) must also be installed on the handheld to provide required Zebra MDNA runtime libraries and allow DataWedge to bind the necessary hardware scanning features. You do not have to use Enterprise Browser as your day-to-day browser — Chrome is the primary interface.

📡 Phase 1: Connect to Wi-Fi
1 Open Wi-Fi Settings
On the Zebra TC53 handheld, swipe up to open the app drawer and tap the Settings gear icon. Select Network & internet, then tap Internet (or Wi-Fi).
2 Connect to the Scanning Network
Select your facility Wi-Fi network or portable scanning hotspot (e.g. M3000-xxxx MiFi). Enter the network security key and tap Connect. Verify the connection status shows Connected.
💡 Offline Support: Once the initial room manifest is loaded in iDash, the Service Worker (sw.js) allows you to continue scanning offline even if Wi-Fi drops out while sweeping deep inside shielded clinical rooms.
🔌 Phase 2: Pair the RFD40 RFID Sled
3 Note the RFD40 Sled Serial Number
Locate the RFD40 Sled Serial Number under the mounting latch/lid of the sled. You will need this serial number to distinguish your sled from others nearby when pairing in Bluetooth.
4 Enable Bluetooth Discovery on the Sled
Press and hold the trigger on the RFD40 sled until the LED on the side flashes blue, indicating Bluetooth discovery mode is active.
5 Pair from the TC53
On the Zebra TC53:
  1. Open Settings → Connected devices.
  2. Tap Pair new device.
  3. Locate the RFD40 entry corresponding to your sled’s serial number.
  4. Tap the device name, then tap Allow and Pair on the Bluetooth confirmation prompt.
Once paired, the RFD40 will appear in your Saved devices list with a steady blue connection indicator.
6 Hardware Reconnection Procedure
If the RFD40 sled ever drops connection during daily use:
  1. Unhook the TC53 from the eConnex mount sled for 2 seconds — the sled will auto-reconnect.
  2. Re-seat the TC53 firmly back onto the sled.
  3. If Bluetooth requires a hard reset, remove the sled battery pack for 5 seconds, reinsert it, and pull the trigger.
📦 Phase 3: Install Zebra Enterprise Browser (Hardware Support Runtime)
7 Install Zebra Enterprise Browser (Package: com.zebra.mdna.enterprisebrowser)
Even though daily scanning is performed in Google Chrome, Zebra Enterprise Browser (EB v5.6+) must be installed on the handheld. Its installation supplies the underlying Zebra MDNA hardware runtime libraries and enables Zebra DataWedge to establish the necessary scanning hooks and keystroke listeners.
  1. Open the Google Play Store on the TC53 (or use Zebra StageNow / Intune MDM).
  2. Search for "Zebra Enterprise Browser" (Package: com.zebra.mdna.enterprisebrowser).
  3. Tap Install. Once installed, you do not need to actively run it — its libraries will be available to the system.
💡 Why this is required for Chrome scanning: When DataWedge imports its database profile in Phase 4, it binds hardware triggers and keystroke wedge listeners to the Zebra web component stack. Having Enterprise Browser installed guarantees that all necessary Zebra barcode and RFID background services are active. (EB also remains on the device as an optional full-screen kiosk alternative).
⚙ Phase 4: Deploy Config.xml & DataWedge Profile
8 Deploy Config.xml (Kiosk & URL Auto-Start)
The Config.xml file tells Enterprise Browser to automatically launch iDash upon startup, enables full-screen kiosk mode (hiding system status bars and navigation keys), and enables the DataWedge scanning hook (usedwforscanning = 1).
  1. Download Config.xml from your iDash server.
  2. Connect the TC53 to your computer via USB-C cable.
  3. On the TC53 screen, pull down the notification tray, tap Charging this device via USB, and change to File Transfer (MTP).
  4. On your PC, open File Explorer and copy Config.xml to the Enterprise Browser configuration directory:
    This PC\TC53\Internal shared storage\Android\data\com.zebra.mdna.enterprisebrowser\Config.xml
⚠️ Set Your Actual iDash Server URL in Config.xml

The URL in the downloaded Config.xml template is an example (pointing to the development gateway https://lingcod.tail585c9b.ts.net:8443/index.aspx). Before or after deploying to your scanners, open Config.xml in Notepad or VS Code and insert your facility’s actual iDash link.

<General>
  <Name value="Menu"/>
  <!-- Replace with your production server URL -->
  <StartPage value="https://<servername>:443/iDash" name="Menu"/>
</General>

Typical production formats: https://<servername>:443/iDash, https://<servername>/iDash, or on an isolated local subnet: http://<server-ip>:8181/index.aspx.

9 Import DataWedge Profile (datawedge.db)
The iDash DataWedge database pre-tunes hardware triggers for the TC53 and RFD40 sled:
  • Bottom Trigger: Activates 2D imager barcode reader (scans linear room barcodes on walls).
  • Top Trigger: Activates RFD40 UHF RFID sled (continuous inventory sweep at 30–50 tags/sec).
  • Keystroke Output & BDF: Automatically appends an ENTER key suffix and suppresses the Android soft keyboard so it never covers the screen.

Import Procedure via DataWedge App:

  1. Download datawedge.db to the TC53 (or copy via USB).
  2. On the TC53, open the DataWedge app.
  3. Tap the 3 vertical dots (⋮) in the upper right corner and select Settings.
  4. Tap Restore database (or Import Profile).
  5. Browse to your downloaded datawedge.db and tap to import.
  6. DataWedge will prompt: "Database restore successful".
💡 Automated USB deployment: You can also copy the entire com.symbol.datawedge folder from Zebra_DataWedge_RFD40_Profile.zip directly into Internal shared storage\Android\data\ via USB-C.
🏁 Phase 5: Launch iDash in Chrome & Verify Scanning
10 Open Google Chrome (or Home Screen Shortcut)
On the TC53, tap Google Chrome (or your 1-tap iDash home screen web shortcut). Navigate to your facility’s iDash server URL:
https://<servername>:443/iDash   (or http://<server-ip>:8181/index.aspx)
Enter your site number and password (e.g. 613), accept the Software Usage Agreement, and tap Sign In.
💡 Optional Kiosk Mode: If you ever prefer a borderless kiosk display that completely hides the browser address bar and prevents exiting, you can also launch Zebra Enterprise Browser at any time — both browsers share the exact same underlying DataWedge scanning profile.
11 Open Inventory & Perform Test Scans in Chrome
From the iDash Hub, tap Inventory (va_inventory.aspx). The high-speed room inventory engine loads with the active room scanner:
  1. Scan Location: Aim at a room location barcode on the doorframe/wall and pull the bottom trigger. DataWedge injects the barcode directly into Chrome — the room code populates instantly and the manifest loads.
  2. Sweep Room: Pull the top trigger on the RFD40 sled to sweep UHF RFID tags in the room. Audio feedback beeps on detected tags, and items update live in Chrome with color-coded status matching.
✓ Verification Complete: Your Zebra TC53, RFD40 sled, and Google Chrome browser are fully calibrated and ready for daily production scanning!

🔧 Troubleshooting

IssueCauseSolution
TC53 cannot connect to Wi-FiHotspot powered off or incorrect passwordVerify the MiFi device is active and broadcasting. Confirm network SSID and re-enter passkey.
RFD40 sled not appearing in Bluetooth listSled discovery timed out or battery depletedHold trigger down until the side LED flashes blue. If no light appears, dock sled in charging cradle.
Sled disconnects during scanningBluetooth sleep timeout or loose mountUnhook the TC53 from the sled mount for 2 seconds and re-seat. Reconnect via Settings → Connected devices.
Enterprise Browser shows connection errorIncorrect URL in Config.xml or no network reachabilityVerify the <StartPage> in Config.xml matches your server IP / Tailscale hostname on port 8181 or 8443.
Scans do not type into iDash input fieldsDataWedge profile not restored or wrong associationRe-import datawedge.db. Ensure com.zebra.mdna.enterprisebrowser is associated in DataWedge profile settings.
On-screen software keyboard obscures screenSoft input panel (SIP) not suppressedIn DataWedge profile, verify Keystroke output is enabled and soft keyboard suppression is active.

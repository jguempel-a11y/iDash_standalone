📱 Guide: Zebra TC53 Scanner Setup

How to connect the Zebra TC53 reader to your MiFi network, pair the RF40 RFID sled via Bluetooth, install the iDash app, and configure it to connect to your print server.

When to use this guide: Follow these steps when setting up a new Zebra TC53 scanner for the first time, or when you need to reconfigure an existing scanner (new server, new sled, or app reinstall).

Source: VISN 5 Use and Configuration Guide for iDash 4.0.8.7, Sections III–IV (pages 14–25)

📡 Phase 1: Connect to WiFi
1 Open WiFi Settings
On the Zebra TC53, tap the Settings icon (gear). Navigate to Network & Internet, then select "Wi-Fi".
2 Connect to the Network
Tap Network & internet, then tap Internet. Find and connect to the same Wi-Fi network as your iDash system.
⚠ Important: Both the printing laptop and the TC53 RFID reader must be connected to the same Wi-Fi network for iDash to work correctly.
🔌 Phase 2: Pair the RF40 RFID Sled
3 Note the Sled Serial Number
Note the RFD40 Sled Serial Number (located under the lid) for identification of the device when you add it to Bluetooth Devices in the next step.
4 Enable Bluetooth Discovery on the Sled
On the RFD40 sled device, press the trigger to enable Bluetooth Discovery Mode. You will see a flashing blue light on the side. Now go to settings on the TC53 and select Connected Devices.
5 Pair from the TC53
On the TC53:
  1. Go to Settings → Connected Devices
  2. Tap "Pair new device"
  3. Scroll down until you find RF40 with the serial number you copied
  4. Tap the correct RF40 sled entry
  5. Tap "Allow" then "Pair"
When paired successfully, the device will appear in your Connected Devices list. Close Settings.
6 Reconnecting After a Dropout
If the scanner disconnects when iDash is opened:
  1. Remove the TC53 from the sled — the scanner will auto-reconnect
  2. Reattach the TC53 to the sled after it reconnects
  3. Verify by tapping "More" → "Connect Scanner" — it should show "scanner already connected" at the bottom of the screen
💡 Still won't connect? Remove the TC53 from the sled, remove the sled's battery, reinsert the battery, then reattach the TC53. This forces a full Bluetooth reset.
📦 Phase 3: Install iDash App
7 Install from Google Play Store
On the TC53:
  1. Open the Google Play Store
  2. Search for "iDash"
  3. Select iDash VA and tap Install
Once installed, close the Play Store.
📡 Already installed? If iDash VA is already on your reader, skip this step and proceed directly to Phase 4 (Configuration). Follow this same process if you need to update the app in the future.
⚙ Phase 4: Configure Server Connection
8 Find the Server IP Address
On the print laptop (not the TC53):
  1. Click the Start button
  2. Type "cmd" in the search bar and open Command Prompt
  3. Type ipconfig /all and press Enter
  4. Scroll down to "Wireless LAN adapter Wi-Fi:"
  5. Note the IPv4 Address — copy it to Notepad for the next step
💡 Example: The IPv4 address will look something like 172.20.0.42. You'll need this exact address for the app configuration.
9 Configure iDash Server Address
On the TC53, open the iDash VA app:
  1. Tap "GET STARTED"
  2. Select "Web Services"
  3. Tap "InApp" then select "Browser"
  4. In the "Server Address:" field, enter: http:// followed by the IPv4 address from Step 8
  5. Tap "Save"
Example: http://172.20.0.42
⚠ Note: The IP address shown is only an example. Use the actual IPv4 address from your print laptop's ipconfig /all output.
10 Set Scanner Type
Still in the app settings:
  1. Find "Scanner Type:"
  2. Tap below "Scanner Type:" and select "Zebra Sled"
  3. Tap "SAVE"
11 Log In
When prompted to sign in:
  • Username: Your Site # (e.g., 512)
  • Password: Your Site # (same as username)
Tap "Login". When "Access Location?" appears, tap "YES", then "ALLOW".
📡 Admin access: For admin-level access (e.g., Baltimore), append a to the site number for both username and password (e.g., 512a).
12 Start Scanning
The RFID reader is now ready to use! Scroll to "SCAN ROOM" to begin your inventory:
  • Bottom trigger — Scan the linear location barcode label on the wall
  • Top trigger — RFID-read the room (bulk tag scanning)
  • You can also barcode-scan individual assets instead of RFID reading
💡 Next steps: See the ADHOC Scanning Guide or Batch Mode Scanning Guide for detailed scanning procedures.

🔧 Troubleshooting

IssueSolution
TC53 won't connect to MiFiVerify the MiFi device is powered on and broadcasting. Check the network name matches M3000-xxxx. Try forgetting the network and reconnecting.
RF40 sled not appearing in BluetoothPress the sled trigger to re-enter discovery mode (flashing blue light). Make sure the sled battery is charged.
Sled disconnects when opening iDashRemove TC53 from sled, wait for reconnect, then reattach. If persistent, remove sled battery, reinsert, and re-pair.
iDash not in Play StoreVerify the TC53 has internet access through the MiFi. Check that your Google account is signed in.
"Server unreachable" after entering IPVerify the laptop and TC53 are on the same MiFi network. Re-run ipconfig /all to confirm the IP hasn't changed.
Login fails with Site #Verify you're using the correct site number. Username and password should be identical (e.g., both 512).
No location permission promptGo to TC53 Settings → Apps → iDash → Permissions and manually enable Location access.

🌐 What is VALIP?

The VA Logistics Integration Platform (VALIP) is an enterprise-level IT platform designed to modernize and integrate the VA's legacy supply chain and logistics systems.

PIA ReferenceFY24 VA Logistics Integration Platform VALIP PIA (July 2024)

What VALIP Provides

  • API Management — centralized gateway for all logistics data exchange
  • Real-time Messaging — event-driven data streaming between systems
  • Service Orchestration — coordinates data flow between AEMS/MERS, RTLS, Maximo, and other systems
  • Data Standardization — normalizes data formats across legacy and modern systems
💡 Why This Matters for iDash:
VALIP is the official middleware layer between external systems (like iDash/AssetWorx) and VA systems of record (AEMS/MERS, VistA). Instead of writing directly to VA SQL databases, the intended integration path goes through VALIP's API gateway.

⚠ Why This Path Was Ruled Out:
The VA Lighthouse API (developer.va.gov) is exclusively for Veteran-facing data: Patient Health (FHIR), Benefits Claims, Appeals, Community Care, etc.

iDash does not store, transmit, or access patient data. We only push supply chain inventory data (equipment locations, last-inventoried dates) to AEMS/MERS. The Lighthouse production access application requires selecting patient-facing APIs — none of which apply to equipment/asset tracking.

Correct path for supply chain: Path A (Direct SQL) or Path C (VALIP).

VALIP is the VA's official middleware for logistics data. An integration through VALIP would:
  • Push data directly into AEMS/MERS (no SQL staging table needed)
  • Survive the AEMS/MERS → Maximo migration
  • Be fully supported and auditable by the VA

📦 AEMS/MERS & RTLS Background

AEMS/MERS (Automated Engineering Management System / Medical Equipment Reporting System)

  • Legacy VA system of record for medical equipment management
  • Runs on VistA / VA FileMan (MUMPS/M database)
  • Manages equipment inventory, maintenance schedules, work orders
  • Being migrated to IBM Maximo under the HELM program

RTLS (Real-Time Location Systems)

  • Technology for tracking equipment locations within VA facilities
  • VA uses various RTLS vendors at different facilities
  • Bi-directional interface with AEMS/MERS:
    • AEMS/MERS → RTLS: equipment details (inventory records)
    • RTLS → AEMS/MERS: updated location data (from scans)

The Current Manual Process (What We're Automating)

  1. Scanner operator performs RFID scan at facility (creates ENNX)
  2. VA staff manually copies ENNX content
  3. VA staff pastes into AEMS/MERS terminal (VistA)
  4. Each asset's location and inventory date updated individually

Our goal: Replace steps 2-4 with a single button click via VALIP or Lighthouse API.

SQLI (SQL Interface) — Patch DI*21.0*38

FileMan's SQLI module provides a relational mapping layer over VistA's hierarchical MUMPS globals, creating SQL-compatible views. Key components:

  • SQLI_TABLE_ELEMENT — maps FileMan fields to SQL columns
  • SQLI_DATA_TYPE — maps MUMPS types to SQL types
  • SQLI_DOMAIN — groups related tables
  • SQLI_KEY_FORMAT — defines primary/foreign key relationships

💡 Key Takeaway for iDash Integration:
The primary protocol for VALIP API integration is HTTPS (REST). SFTP is used for file-based transfers (CDW reporting, FMS confirmations). SMTP/TCP is used for VistA Mailman (IFCAP transactions). Our current Path A (Direct SQL) bypasses VALIP entirely; Path C would use the HTTPS channel.

3. Zero Trust Architecture (ZTA) Requirements

VALIP implements Zero Trust via the Zscaler ZPA IL5 SaaS solution with the Zscaler Application Connector. This ZTA capability:

  • Protects all VA Information Systems that leverage VALIP as their integration platform
  • Extends to support SaaS and multi-cloud integrations
  • Enforces least-privilege per-request access decisions
  • Treats the network as potentially compromised (zero trust posture)
  • Integrates visibility from multiple vantage points with automated detection and response
⚠ Implication for AssetWorx:
Any future VALIP integration (Path C) will require compliance with ZTA requirements. This likely means mTLS certificates, application-level authentication tokens, and approval through the Zscaler Application Connector for our traffic to reach VALIP endpoints.

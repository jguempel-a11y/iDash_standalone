👀 VA Asset Explorer

Database Connected Dynamic Grid Rendering

The VA Asset Explorer (va_asset_api.aspx) is a fast, focused asset lookup tool designed for rapid single-record investigation. While the Data Research Portal is optimized for bulk querying and spreadsheet analysis, the Asset Explorer is streamlined for quickly finding one or more specific assets by barcode, description, or RFID tag and immediately viewing all key fields in a scannable, column-toggled grid — ideal for field leads and administrators verifying individual records.

How to Use

On Page Load

The page immediately queries and displays the 200 most recently modified asset records from dbo.asset ordered by lastmodified DESC. This gives instant visibility into recent activity without needing to enter a search term.

Searching for Assets

Enter any of the following in the search box and click Load (or press Enter):

  • EE Barcode (e.g., 512 EE12345) — matched against name
  • Description keyword (e.g., wheelchair) — matched against description
  • RFID EPC tag (e.g., E28068940000400158AB1234) — matched against rfidtag
  • Partial string — all three fields are searched with LIKE '%term%' simultaneously
ℹ Tip: Searching a partial barcode like EE123 will match any asset whose barcode contains that string. This is useful when you only have a partial scan or a hand-written number.

Column Chooser

Click the Columns button to open the column chooser panel. All database columns from the dbo.asset view are listed. Toggle any column on or off to show exactly the fields you need. The default visible set includes the most commonly referenced fields: 

id • name • description • lastobservedlocation • lastobservedtime
listvalue1 • text6 • text8 • text16 • text19
lastmodified • lastmodifiedby • lastinventoried • companyid • locationname

Clearing Results

The Clear button resets the search box and reloads the default 200 most-recent assets, returning the grid to its baseline state.

Technical Architecture

The Asset Explorer uses a fully server-rendered grid approach. On each search or page load, the C# backend executes a parameterized SQL query, loads the result into a DataTable, and dynamically generates the full HTML table including column headers, data rows, and the column chooser checkbox list. Client-side JavaScript handles column toggle visibility, debounced filter input, and chooser search — all without additional server round-trips after the initial render.

SQL Query Executed on Search

SELECT TOP (@top) *
FROM dbo.asset
WHERE description LIKE @like
   OR name         LIKE @like
   OR rfidtag      LIKE @like
ORDER BY lastmodified DESC

Access & Security

Access is controlled via the iDash tile-key model. Users must have the asset_api tile key in their TileAccess profile. Typically granted to field leads and administrators. See User Management for details.

All queries use SqlParameter for full SQL injection prevention. The search term is passed as @q (exact) and @like (wildcard) parameters — never interpolated into the SQL string directly. No raw database errors are surfaced to the browser.

⚠ Read-Only: The Asset Explorer is a display-only tool. It does not allow editing, deleting, or creating asset records. For record modifications use the iDash desktop application or the appropriate iDash scanning workflow.

📡 Guide: ADHOC Scanning & Inventory

How to perform ad-hoc asset scans using the handheld RFID reader, review scan results, and sync data back to AssetWorx.

What is ADHOC Scanning? Ad-hoc scanning lets you perform quick inventory audits of any location without a pre-defined work order. Walk into a room, scan all tags, and AssetWorx automatically updates asset locations and flags misplaced items.

Source: VISN 5 Use and Configuration Guide for AssetWorx! 4.0.8.7, Section I (pages 4–6)

1 Open ADHOC Mode
On the handheld scanner (Zebra TC53 with RFID sled), open the AssetWorx! app from the home screen. From the main menu, tap "Adhoc" to enter ad-hoc scanning mode.
💡 Tip: ADHOC mode is different from "Inventory" mode. ADHOC is for quick spot-checks; Inventory mode is for comprehensive, work-order-based sweeps.
2 Select a Location
Select the location where you want to perform the scan. You can:
  • Search — Tap the lookup field and type a room number, building name, or location code
  • Scan a Location Tag — If the room has an RFID location tag on the wall, scan it to auto-select the location
  • Browse — Scroll through the location list to find the correct room
Verify that the correct location is shown on the screen before proceeding.
3 Start Scanning
Tap the "Start" button to begin scanning. Hold the trigger on the gun/sled reader and slowly sweep the room. As RFID tags are read:
  • The reader beeps for each tag detected
  • A running list of scanned assets populates on screen showing Tag ID, Asset ID, and Status
  • The scan count increments in real time
📡 Scanner Tips: Point the antenna at equipment shelves, cabinets, and walls. RFID can read through most materials. Sweep slowly and cover all areas of the room for best results.
4 Stop Scanning & Review Results
When you've finished scanning the room, tap "Stop". The results screen shows four tabs:
✅ Scanned 📋 Expected ⚠ Misplaced ✨ New
TabWhat It Shows
ScannedAll assets detected in the current location during this scan session
ExpectedAssets registered to this location in the database but not yet scanned — these may still be in the room (check behind furniture/cabinets)
MisplacedAssets scanned here but registered to a different location in the database. These items have moved.
NewTags detected that don't exist in the database at all — possibly unregistered equipment
5 Sync to AssetWorx
Tap "Sync" to upload your scan data to the AssetWorx database. This will:
  • Update locations — Misplaced assets are moved to their new scanned location
  • Record scan history — A timestamp is saved for each scanned asset (used for inventory age reporting)
  • Generate session data — The scan session appears in iDash Reports for auditing
A progress bar will display during sync. When complete, you'll see: "Sync completed successfully. X assets updated."
⚠ WiFi Required: The scanner must be connected to WiFi to sync. If you're offline, see the Batch Mode Scanning Guide for how to scan offline and sync later.
6 Verify in iDash
After syncing, you can verify the updated asset locations in the iDash web portal:
  • Asset Master — Search for specific assets and check their "Last Inventoried" date
  • Session Reports — View the scan session with counts of scanned, misplaced, and new assets
  • ENNX Reports — Generate Equipment Not in Expected location reports

🔧 Troubleshooting

IssueSolution
Scanner not reading any tagsCheck that the RFID sled is powered on and paired. Try adjusting antenna power (see Adjusting Reader Power)
Location tag not recognizedThe location tag may not be registered in AssetWorx. See Missing Location Tag
Sync fails with errorVerify WiFi connection. Move closer to the access point. If persistent, switch to Batch Mode
All assets show as "Misplaced"You may have selected the wrong location. Verify the location name matches the room you're in.
Expected tab shows assets I scannedSome assets may have weak tags. Try rescanning from closer range with higher antenna power.

📝 System Logs & DB Automation

Database Connected File System Access Scheduler Ready
🔎 What This Page Does: This is iDash's central hub for monitoring automation activity and managing scheduled database updates. It replaces the old separate "System Logs" tile by combining the DB update log viewer, the Field Server Sync log, and a gateway to the full IIS & App Log Analyzer.

Module Purpose

The System Logs & DB Automation page (va_autodbupdate.aspx) serves two main jobs:

1
System Log Viewer (Tab 1): View logs from the Auto DB Update processor, the Field Server Sync nightly sync, and the full IIS web server & .NET app logs.
2
DB Automation (Tab 2): Monitors a watch folder for incoming data files, runs a configurable SQL script against them, and archives processed files.

Who Should Use This Page?

This page is administrator-only. It is reached through the Admin & Database Tools section on the iDash hub.

RoleAccess?Why
Standard UserNo AccessProtected behind admin login
Site AdministratorFull AccessMonitors automation health
Scheduled TaskSilent APITask Scheduler calls ?auto=1

Tab 1 — System Log Viewer

🗃 Database Update Log (va_autodbupdate.log)

Written every time the Auto DB Update processor runs (manually or automatically).

  • Timestamp of the run and SQL script path used
  • Which files were found and total rows affected
  • Final disposition and any errors that occurred

🔁 Field Server Sync Log (va_field_sync.log)

Records each run of the nightly Field Server Sync process.

Tab 2 — DB Automation

▶ Normal Processing Flow: Incoming data files dropped in the watch folder are detected, processed via SQL, and then moved to an archive folder.

Settings You Can Configure

SettingDefault ValueDescription
Watch FolderC:\VA_RFID\va_dbupdate\autoloadFolder scanned for incoming data files.
SQL Script Path...\va_dbupdate.sqlThe SQL script executed on each update run.
⚠ Important: Use the {{DATAFILE}} token in your SQL script — it is automatically replaced at runtime with the full detected filename.

Scheduled Automation

The page supports silent, unattended processing via a URL parameter for Windows Task Scheduler:

powershell.exe -Command "Invoke-WebRequest -Uri '.../va_autodbupdate.aspx?auto=1'"

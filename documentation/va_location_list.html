Location List

Database Connected Updated 08/21/2026

Module Purpose

Provides a sortable, paginated, filterable summary of every asset location: total assets, unique CMR numbers, age-bucket breakdowns (0–3 mo through 13+ mo), percentage coverage, and last inventoried date. Drill into any location to see individual assets, or filter by age bucket across all locations.

Source Architecture

Frontend: va_location_list.aspx
Backend: va_location_list.aspx.cs
SQL view: dbo.v_asset (ADO.NET inline)
Auth: IsAdminAuthenticated + tile access (rpt_location_list or rpt_asset_master)

Key Features

  • 📈 KPI Dashboard Cards
    Five animated summary cards: Total Assets, Locations, CMR Coverage %, 0–3 Month %, and 13+ Month Overdue. Age distribution bar shows proportional color-coded segments for all 5 buckets.
  • 🔍 Age-Bucket Filter Pills
    0–3 mo, 4–6 mo, 7–9 mo, 10–12 mo, 13+ mo, and Show All. Results load in the Filter Detail panel with inline column sort and col-search filter inputs (native JS — no DataTables dependency).
  • 📋 Sortable Column Headers New 08/21
    All columns clickable. Numeric/date columns sort descending first (largest/newest first); text columns sort A–Z first. Active sort column highlights in accent color with a solid ▲ or ▼ arrow. Persists across paging and column filters.
  • 📄 Rows Per Page + Persistent Pager New 08/21
    Choose 10, 20, 50, or 100 rows. Defaults to 10. Choice saved in localStorage — survives postbacks, refreshes, and new sessions. Current page number is also restored after clicking a location and returning.
  • 🔍 Per-Column Filter Inputs
    Text inputs under each header filter rows live. Combined AND logic. Filtering resets to page 1 and re-applies the active sort.
  • 🔗 Location Row Click — Asset Detail Fixed 08/21
    Clicking a location name loads all assets at that location via server postback. Page auto-scrolls to the detail panel. The selected row is highlighted. A ↑ Back to Locations button scrolls back to the grid smoothly.
    Fix note: Previously broken because DataTables was wrapping the summary grid and intercepting ASP.NET __doPostBack click events. Now uses a native JS filter+pager that leaves postback intact. DataTables has been removed entirely from this page — detail grids use the lightweight initDetailFilter() helper instead.
  • ⚠ Unique CMR Column New 08/21
    COUNT(DISTINCT …) of real CMR values per location. Excludes placeholders: NULL, UNKNOWN, N/A, NA, NONE, TBD, ?. A location with 5 UNKNOWN + 2 real CMRs shows Unique CMR = 2.
  • 💾 Export Excel
    Context-aware export: if a location is open, exports only that location’s assets (file named Assets_{Location}.csv); if an age-bucket filter is active, exports that filtered set (Assets_Age_Filter.csv); otherwise exports the full location summary grid (Location_Summary.csv). Data is served from the server-side Session cache — no second query is issued, making export instant.

Navigation Flow

  1. Select a Site (or All Sites) and optionally filter by CMR or location text.
  2. Use age-bucket pills to filter by inventory freshness.
  3. Click any column header to sort; click again to reverse.
  4. Use per-column filter inputs to narrow the visible rows.
  5. Choose rows per page (10/20/50/100) — your choice is remembered.
  6. Click a location name → page scrolls to detail panel with all assets.
  7. Click ↑ Back to Locations to return to your position in the grid.

Deployment & Portability

No dependency on UserManager.FilterCompanyDropdown or other methods that may differ between iDash instances. Uses UserManager.GetAllowedCompanyIds() which is universally available. Safe to copy between systems.

Use deploy_to_target.ps1 (iDash root) to push changed files to another system without a full robocopy traversal. This prevents the "There can be only one 'page' directive" parser error caused by file-append during copy.

Technical Notes

  • Summary grid uses native JS pager + filter (not DataTables) to preserve LinkButton postback. Detail grids use the lightweight initDetailFilter() helper — DataTables is not used on this page.
  • Pager state stored in localStorage: loc_page_size, loc_page_num, loc_selected.
  • Unique CMR SQL: COUNT(DISTINCT CASE WHEN UPPER(LTRIM(RTRIM(text8))) IN ('NULL','UNKNOWN','N/A','NA','NONE','TBD','?') THEN NULL ELSE LTRIM(RTRIM(text8)) END)
  • Tagged status uses a.text18 = '1' (not rfidtag).

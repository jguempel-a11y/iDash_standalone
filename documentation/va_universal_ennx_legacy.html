This document describes the original, legacy implementation of va_universal_ennx_legacy.aspx (formerly va_universal_ennx.aspx).
This version featured square KPI tiles, tethered WebSerial USB port controls, and client-side blob downloads.
The active production version is now the streamlined, high-speed va_universal_ennx.aspx (v2.0) featuring an $O(1)$ memory engine (30–50 tags/sec), unified single-row count & filter toolbar matching va_inventory.aspx, 4-color status rows, and direct email dispatch.

File: va_universal_ennx_legacy.aspx / va_universal_ennx_legacy.aspx.cs

Status: RETIRED & ARCHIVED (September 2026) — Preserved for audit & fallback.

Target Hardware: PC browsers, USB tethered serial readers, and legacy barcode scanners.

Original Purpose: Self-contained ENNX generation without site selection, EIL filtering, or SQL Server connection.

Legacy Interface Features

1. Square KPI Cards

The legacy screen occupied four separate square KPI summary tiles at the top of the interface:

  • Locations (#kLoc): Total distinct room blocks encountered.
  • Assets (#kAssets): Total equipment barcode entries added.
  • Duplicates Skipped (#kDupes): Assets scanned twice in the same room.
  • Mode (#kMode): Status indicator showing current scan mode.

2. WebSerial API Support (Tethered USB)

The legacy interface included a collapsible <details> panel with serial port controls allowing tethered USB readers to be connected directly to the browser (115200 baud, 8N1, hardware flow control). Note: This was retired in v2.0 in favor of wireless operation on Zebra TC53 / RFD40 handhelds.

3. Client-Side Blob File Download

The legacy interface offered a "Download ENNX" button that constructed a client-side Blob and generated a transient <a download="..."> click event to download .txt files directly to local storage.

4. Legacy Session Auto-Recovery

Persisted scan blocks to localStorage under UniversalEnnx_SessionBlocks.

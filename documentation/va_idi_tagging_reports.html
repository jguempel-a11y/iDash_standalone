IDI Tagging Data Reports

The IDI Tagging Data Reports executive dashboard (va_idi_tagging_reports.aspx) provides an aggregated, real-time overview of the tagging progression via visual KPIs, charts, and metric tables. It is crafted primarily for use by leadership (CLO) offering immediate insights into deployment statistics without requiring manual report execution.

How It Works

The dashboard is powered by a front-end UI displaying Chart.js driven visuals, while the back-end (va_idi_tagging_reports.aspx.cs) handles direct JSON responses representing SQL aggregates.

  • Data Source: Queries the v_asset view, isolating records tagged with text18 = '1'.
  • API Layer: Acts as its own API endpoint. Passing ?api=dashboardstats&range={time_period} allows the front-end to request the live numbers.
  • Auto-Refresh: The page invokes JavaScript's setTimeout to recursively ping the endpoint every 5 minutes (300,000ms), ensuring an unattended monitor will always reflect active tagging outputs.
  • Live UI Filters: Time ranges such as Today, This Week, and This Month execute zero-reload AJAX calls that dynamically re-render the charts and KPI ticker animations upon receipt of new data.

Calculated Data Points

Metrics on the dashboard map specific database variables to functional descriptions:

  • Total Assets Tagged: Derived directly from the condition text18 = '1'.
  • Tag Types Deployed: A discrete count of values in the text19 column where tracking represents typologies like "IQ350" or "Metal".
  • Personnel Tagging: Distinct counts of text13 representing unique employee IDs executing the tagging logic.
  • Active Locations: Count of the locationname field among successfully tagged equipment.
  • Charts: Top 10 locations bar chart categorizes counts by locationname, and the pie diagram processes percentages by counting text19 tag types.

Exports Integration

The page bridges the gap between executive high-level viewing and direct data manipulation by providing static outbound links to the legacy automated processes. Leadership can click the corresponding panels to jump directly to va_ennx.aspx to review scheduled log output payloads, or to va_tag_stats.aspx for full Excel flat-file dumps of the metrics.

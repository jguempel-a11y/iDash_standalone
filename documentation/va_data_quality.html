The Data Quality Command Center (va_data_quality.aspx) provides comprehensive data health auditing, automated anomaly detection, weighted scoring (0–100), and interactive drill-down previews across 600,000+ VA equipment records.

1. Purpose & Operational Role

Accurate RFID tracking and VistA/AEMS-MERS reconciliation depend directly on consistent metadata. Data anomalies — such as missing EIL/CMR identifiers, blank locations, unconventional asset naming, or obsolete status values — prevent handheld scanners from loading room lists and cause false ENNX discrepancies.

The Data Quality Command Center identifies, categorizes, and quantifies these data defects in real time, giving VISN leadership and site data administrators an immediate, objective grade on data readiness.

2. Data Quality Scoring Algorithm

The overall data quality score is calculated on a 0 to 100 scale using a weighted penalty formula based on four key integrity dimensions:

Dimension Weight Severity Detection Logic Operational Impact
Missing EIL / CMR 40 pts High text8 IS NULL OR text8 = '' Cannot be grouped into CMR inventory batches; fails VistA sync.
Missing Location 25 pts High locationid IS NULL Cannot be verified during room sweeps; always flagged as misplaced.
Malformed EE Name 25 pts Medium Name does not match [Station] EE[0-9]+ standard Fails barcode lookup rules and handheld scanner regex matchers.
Status Not 'In Use' 10 pts Low listvalue1 <> 'In Use' (5% allowance) Indicates assets marked as Disposed, Turn-In, or Storage still in active tables.

Letter Grade Thresholds

  • A — Excellent (90–100): Clean data; ready for full production automation.
  • B — Good (80–89): Minor metadata gaps; safe for operational inventory sweeps.
  • C — Fair (70–79): Moderate naming or CMR deficiencies; remediation recommended.
  • D — Poor (60–69): Significant location or EIL omissions; impacts field scanning accuracy.
  • F — Critical (< 60): Major structural defects; requires immediate database reconciliation.

3. Core Features & Workflow

  • Facility & Company Filtering: Dropdown allows filtering data quality metrics across all sites or targeting a specific medical center (e.g., 512 Perry Point, 540 Clarksburg, 613 Martinsburg). Multi-tenant permissions restrict users to their authorized sites.
  • Interactive AJAX Data Previews: Each issue card features a Preview (Top 50) toggle that loads records via fast JSON API (va_data_quality.aspx?api=preview) without refreshing the entire page. Includes inline client-side column filtering.
  • Bulk Excel Export: Clicking Export All downloads a full multi-tab or combined Excel spreadsheet containing all flagged records for offline remediation and field coordination.
  • Direct Hub Integration: Accessible from the Reports section of the main iDash portal (index.aspx) and integrated with Asset Master search filters.

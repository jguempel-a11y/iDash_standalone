📡 Guide: Running ADHOC File Generation

How to run AdHoc in Above PAR report to create the EQUIPMENT.xlsx excel sheet template.

Source: VISN5 Use and Configuration Guide for AssetWorx ver.004

1 Run AdHoc in Above PAR
Run AdHoc in the Above PAR report to create the EQUIPMENT.xlsx excel sheet template with desired EE tag information.

Below are examples of the precise AdHoc Field Selections and Order numbers needed to pull this Report.
Example A (Specific EE numbers):
By putting in First Condition with an EE number you will only pull that EE number. If you put in a Second Condition with an EE number, it will pull Two EE numbers. If you do not put any conditions, it will pull every EE number in the system.
Example B (Range of EE numbers):
First condition as Greater Than, and the EE number before the EE number you want through to the last created EE number. (if you want to start at EE46795, put in EE46794)
Example C (By Date Entered):
If you need to pull EE numbers by Date Entered, add Date Entered Field Selections, add First Condition as Equal to and the date you created the Equipment.
⚠ CRITICAL: If you use Example C to pull by Date Entered, after you pull the report in Excel you MUST Delete the Date Entered Column before emailing it to visn5martinsburg@id-integration.com!
2 Preview and Export to Excel
After running the AdHoc report Click on Excel, this will be the excel you will e-mail.

Or Click on Preview to check what was pulled first, then click on Excel.
3 Format the Excel File
On the Excel, change tab name to exactly SHEET1, Change and save file name exactly as EQUIPMENT.XLSX.
4 Email the File
Now you are ready to Send an email to visn5martinsburg@id-integration.com and attach the Excel you just created.

Module Purpose

The Asset Statistics dashboard is a consolidated executive reporting suite. It unifies four previously standalone tools into a single, high-performance interface. The module provides real-time overviews of total asset counts, deep-dive data quality metrics, tracking for tagged assets not currently in use, and deep statistical analytics such as category breakdown and scan velocity.

Consolidated Tab Architecture

  • 📈 Asset Overview
    Top-level KPIs, inventory aging metrics across 1/3/6/12 month buckets, and a sortable table detailing complete and overdue asset counts across all physical locations.
  • ⚠ Data Quality
    Previously va_data_quality.aspx. Ranks physical stations by a "Quality Score" calculated from completeness of Location and EIL assignments. Allows direct drill-down into specific problematic records (Missing EIL, Missing Location).
  • 🚫 Not In Use
    Previously va_not_in_use.aspx. Isolates assets that are physically stickered but logically marked with a disposal status (Turned In, Lost, Mismatched, etc). Includes a full drill-down data table.
  • 📊 Analytics
    Visualizations detailing the asset population by Category (Text4 element), Scan Velocity (how fast tags get seen relative to issuance), and the top un-swept stations.

Technical Operation

To ensure high rendering speeds, the interface utilizes a hybrid loading model. The Asset Overview (Tab 1) is rendered directly on page load using ADO.NET SQL DataReaders to build the literal HTML components and GridView. The remaining three tabs (Quality, Not In Use, Analytics) load asynchronously via AJAX (fetch) within 2 seconds of page generation.

These background fetches ping the same page under the hood (e.g. va_asset_stats.aspx?api=dqstats), hitting a specialized internal API router. The C# code-behind aggregates data efficiently using SQL GROUP BY and COUNT() operations, then returns pure JSON to the frontend for Chart.js rendering and DOM injection.

📦 Downloads & Uploads

File System Auth Required

Module Purpose

The Downloads & Uploads page serves as iDash's secure file exchange center. It provides two core capabilities:

  • Downloads — Browse and download approved software, printer templates, drivers, licenses, and other files organized by category folder.
  • Uploads — Customers and employees can send files directly to the iDash team without needing admin credentials. Uploaded files land in a monitored uploads/incoming/ directory with sender metadata.

Authentication

Users must sign in with iDash credentials to access the page. Once authenticated:

  • All users can browse downloads and upload files via the "Send Files to iDash" section.
  • Admin users can also use the "+ Add Files" button to upload files directly into download category folders (requires secondary authentication).

Downloads Section

Files are organized into category folders under the downloads/ directory on the server. Categories are displayed in a defined order:

  1. Software
  2. Reports
  3. Administrative
  4. Licenses
  5. Drivers
  6. Printer Templates

Each file tile shows the filename, file size, and last modified date. Files are served securely with directory traversal prevention and FileShare.ReadWrite to avoid locking conflicts.

The Software/ directory contains datawedge.db, Zebra_DataWedge_RFD40_Profile.zip, and Config.xml for Zebra TC53/TC53E/TC58 mobile computers. Customer / Employee Upload Section

Located at the bottom of the page, the upload section allows anyone who is signed in to send files to the iDash team. No admin privileges are required.

Upload Form Fields

Field Required Description
Your Name Yes Sender's name for identification in the manifest file.
Note No Optional context about the file (what it's for, instructions, etc.).
File Yes Click to browse or drag-and-drop. Max 100 MB.

How Uploads Are Stored

Uploaded files are saved to uploads/incoming/ relative to the iDash root. The directory is created automatically on first upload.

Filename format:

20260722_093412_JaneSmith_quarterly_report.xlsx

Each uploaded file also gets a companion .info.txt manifest containing:

Sender: Jane Smith
Date: 2026-07-22 09:34:12
Original Filename: quarterly_report.xlsx
IP: 10.6.1.42
Note: Updated Q3 asset reconciliation data for VISN 5

Security Controls

  • Blocked extensions: .exe, .bat, .cmd, .com, .scr, .pif, .vbs, .js, .wsf, .msi, .dll — users are prompted to ZIP these instead.
  • File size limit: 100 MB enforced server-side.
  • Sender name sanitization: Non-alphanumeric characters are stripped from the filename portion.
  • Isolation: Uploads go to uploads/incoming/, completely separate from the downloads/ directory tree.

Admin File Upload (+ Add Files)

Admins can toggle the "+ Add Files" panel to upload files directly into download category folders. This requires a separate authentication step (iDash credentials or pre-existing session). Uploaded files appear immediately in the download grid after a page refresh.

Source Architecture

Frontend Structure: va_downloads.aspx
Backend Processing: va_downloads.aspx.cs
Download Files: downloads/{category}/{filename}
Incoming Uploads: uploads/incoming/{timestamp}_{sender}_{filename}

Drag-and-Drop Support

The upload dropzone supports both click-to-browse and HTML5 drag-and-drop. When a file is dragged over the zone, the border highlights with the accent color. The selected filename is displayed in the dropzone label before submission.

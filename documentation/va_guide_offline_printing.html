🖨 Guide: Offline Printing Station

How to use the standalone RFID printing station to print asset labels from BarTender — including Daily Scans Tagging, Emailed Labels, and Supply Chain categories.

What is the Offline Printing Station? A dedicated workstation with BarTender and an RFID printer for printing asset labels. It operates independently from iDash and can be used when the main print server is not available.

Source: VISN 5 Use and Configuration Guide for iDash 4.0.8.7, Section II (pages 7–13)

1 Open the BarTender Desktop
On the printing station computer, open the desktop. You should see three shortcuts:
  • iDash — Opens the iDash web application
  • RFID Printing — Opens the BarTender print interface
  • iDash ENNX Reporting — Opens the ENNX report generator
Click "RFID Printing" to open the BarTender print interface.
2 Navigate to Print Templates
BarTender opens in a browser window showing the Templates folder. You'll see the following print categories as folder icons:
📁 Daily Scans Tagging
For scanning equipment during inventory or for EIL locating. Used during daily rounds.
📁 Emailed Labels
Items created by users and emailed to the print station to be printed. Labels arrive as print-ready jobs.
📁 Supply Chain
Reprint labels for supply chain assets. Used for reprinting damaged or missing labels.
Click on the category folder that matches your print job.
3 Select a Label Template
Inside the category folder, you'll see the available label templates. Common options include:
  • Large_Excel — Large RFID label for high-visibility tagging
  • Small_Excel — Standard small RFID label
  • Std_Small_Excel — Standard format small label
  • Q350_Excel — Q350-specific label format
Click on the desired template to open it.
📡 Template naming: Templates ending in _Excel are designed to read data from an Excel spreadsheet. The spreadsheet should already be configured with the asset data.
4 Verify the Data Source
The template opens with the asset data pre-loaded from the connected Excel file. Verify:
  • The asset name is correct
  • The tag type matches the physical label loaded in the printer
  • The record count matches the number of labels you want to print
⚠ Check the printer first! Before printing, verify that:
  • The RFID printer is powered on and online (green light)
  • The correct label media is loaded (matching the template size)
  • There is enough label stock for the full print job
5 Print Labels
Click the "Print" button (or press Ctrl+P). In the print dialog:
  1. Verify the correct printer is selected (it should be the RFID label printer)
  2. Set the quantity (usually 1 copy per label)
  3. If printing a range, set From and To record numbers
  4. Click "Print" to start
The printer will feed labels and encode each RFID chip during printing. You'll hear the printer motor and see labels advancing.
6 Verify Printed Labels
After printing, verify each label:
  • Visual check — Text and barcodes are printed clearly, no smearing or misalignment
  • RFID check — Hold a handheld scanner near the label to verify the RFID chip was encoded correctly
  • Peel & apply — Remove the label from the backing and apply to the asset in the designated location
💡 Tip: If a label fails to encode (the printer voids it with a line through it), the RFID chip may be defective. The printer will automatically retry with the next label in the roll.

🔧 Troubleshooting

IssueSolution
BarTender won't openCheck that the BarTender license is active. Open BarTender directly from Start menu to see license status.
No categories/folders showingThe template folder path may have changed. Check BarTender settings for the correct template directory.
Excel data not loadingThe Excel file may have been moved or renamed. Verify the data source connection in the template.
Printer not respondingCheck USB/network connection. Power cycle the printer. Verify it appears in Windows Devices and Printers.
Labels printing blank (no RFID)The label media may not have RFID inlays. Check that you loaded RFID-enabled label stock, not standard labels.
Every label gets voidedThe RFID encoding is failing. Check antenna alignment, media type setting, and try a fresh roll of labels.
Wrong data on labelsVerify the Excel spreadsheet has the correct data. Check that the template is pointing to the right columns.

📡 Guide: Batch Mode Scanning & Sync

How to use Batch Mode for offline RFID scanning when WiFi is unavailable, and how to sync stored scan data back to iDash when connected.

When to use Batch Mode: Use batch scanning when you're in a location without reliable WiFi. Scans are stored locally on the device and uploaded when you return to a connected area.

Source: VISN 5 Use and Configuration Guide for iDash 4.0.8.7, Section V (pages 26–31)

⚙ Phase 1: Enable Batch Mode
1 Open iDash Settings
On the Zebra handheld scanner, open the iDash app. From the main menu, tap Settings (gear icon) in the top-right corner.
2 Enable Batch Mode
In Settings, find the "Batch Mode" toggle and switch it ON.
  • When Batch Mode is ON, the app stores all scans locally on the device instead of sending them to the server in real time
  • A batch icon appears in the status bar to indicate you're in offline mode
  • You can scan multiple rooms/locations before syncing
⚠ Remember: Batch Mode must be explicitly enabled before going offline. If you forget and lose WiFi mid-scan in normal mode, data may not sync properly.
📡 Phase 2: Scan Locations
3 Select a Location & Scan
Just like regular ADHOC scanning, select a location and tap Start. Hold the trigger to scan RFID tags. The scanner works identically to online mode — you'll hear beeps and see tag counts.
The key difference: data is stored locally on the device instead of being sent to the server.
4 Scan Multiple Rooms
After finishing one room, tap Stop, then navigate to the next location. You can:
  • Scan multiple locations in sequence without syncing
  • The device stores all scan sessions separately, tagged with their location
  • You can review stored scans by tapping "Batch Queue" or "Pending Syncs" on the main menu
💡 Tip: The device can store thousands of tag reads before running low on storage. You can comfortably scan an entire floor or building wing before syncing.
🔃 Phase 3: Sync Stored Data
5 Return to WiFi Coverage
When you're back in a WiFi-connected area (or near an access point), verify the device has connected:
  • Check the WiFi icon in the status bar — it should show a connected signal
  • If it doesn't auto-connect, go to Settings → WiFi and select your network
6 Sync Batch Data
Open the iDash app and tap "Sync" or "Upload Batch". The app will:
  1. Connect to the iDash server
  2. Upload all stored scan sessions one at a time
  3. Show a progress bar for each session
  4. Display a "Sync Complete" message with the total count of uploaded records
📡 What happens during sync: Each stored session is processed exactly like a real-time scan — asset locations are updated, misplaced items are flagged, and scan history timestamps are recorded.
7 Verify & Clear Batch Queue
After a successful sync:
  • The Batch Queue should be empty (all sessions uploaded)
  • Verify in iDash → Session Reports that your scan sessions appear with correct timestamps
  • If any sessions failed to upload, they'll remain in the queue — tap "Retry" to re-attempt
⚠ Critical: Do NOT uninstall or reset the iDash app before syncing. Unsent batch data is stored on the device only and will be permanently lost if the app is cleared.

🔧 Troubleshooting

IssueSolution
Sync fails with "Server unreachable"Confirm WiFi is connected and iDash server is reachable. Try pinging the server IP from device settings.
Batch icon doesn't appearBatch Mode may not be enabled. Go to Settings and verify the toggle is ON.
Some sessions fail to uploadThe server may reject sessions with invalid locations. Check the error message and verify the location exists in iDash.
Battery dies before syncBatch data persists across restarts. Charge the device, reopen iDash, and sync again.
"Duplicate session" warningThis session was already uploaded. Safe to dismiss — iDash prevents duplicate processing.
Slow sync with many sessionsNormal. Each session is processed server-side. Large batches (50+ rooms) may take several minutes.

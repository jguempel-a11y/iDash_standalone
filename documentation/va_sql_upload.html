SQL Upload

Integrations:
Database Connected

Module Purpose

This module provides a dedicated interface for SQL Upload within the iDash iDash ecosystem. It enables personnel to interact securely with underlying data processes.

Technical Operation

The system primarily renders the user interface through the web endpoint va_sql_upload.aspx. It securely queries the iDash SQL database using inline ADO.NET connections (SqlConnection), leveraging configured network credentials to safely retrieve or update asset tracking records.

Source Architecture

Frontend Structure: va_sql_upload.aspx
Backend Processing: va_sql_upload.aspx.cs

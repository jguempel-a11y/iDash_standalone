AssetWorx ENNX Batch Diagnostics

Integrations:
Database Connected

Module Purpose

Generates, reviews, or filters dedicated ENNX export report logic for government system synchronization.

Technical Operation

The system primarily renders the user interface through the web endpoint ennx_batch.aspx. It securely queries the AssetWorx SQL database using inline ADO.NET connections (SqlConnection), leveraging configured network credentials to safely retrieve or update asset tracking records.

Source Architecture

Frontend Structure: ennx_batch.aspx
Backend Processing: ennx_batch.aspx.cs

Change Log

2026-07-01
  • Critical Fix: dbo.v_asset → dbo.asset — Changed both the summary query and the GetAssetsForDay() detail query from dbo.v_asset to dbo.asset. The v_asset view uses INNER JOINs that filter out assets missing company or location foreign-key relationships, causing recently-scanned assets to not appear in batch reports. The existing LEFT JOIN dbo.location was preserved.
  • Fix: a.locationname column removed — The locationname column only exists on the v_asset view (via a join). Replaced ISNULL(l.name, a.locationname) with ISNULL(l.name, a.text16) (LocationTagged) and removed a.locationname from the COALESCE fallback in the ORDER BY clause.

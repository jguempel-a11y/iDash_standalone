📤 Universal ENNX Creator — Version 2.0

Active Production v2.0 No Database Required Direct Email Export Zebra TC53 / RFD40 Optimized

Overview & Architecture

The Universal ENNX Creator (v2.0) is an enterprise, scanner-agnostic ENNX submission file builder designed for rapid physical inventory across any VA facility without requiring a direct database connection, site filter, or EIL configuration.

Operating natively on the Zebra TC53 / RFD40 handhelds as well as desktop workstations, the v2.0 engine processes high-speed scan bursts (30–50 tags/sec) using an $O(1)$ memory engine, automatically partitions scans by room location barcodes (SP...), suppresses duplicate reads, presents a 4-color stream reconciliation table, and emails validated ENNX files directly to logistics teams.

Operational Workflow

  1. Start Room Location: Scan any room location barcode starting with SP (e.g. SP009-BD. 8A) or click Force Location to mark the next scan as a location.
  2. Pull RFID Trigger / Scan Assets: Sweep the room. All equipment barcodes (e.g. 517 EE35607) are grouped under the active room block.
  3. Switch Rooms Seamlessly: When moving to the next room, simply scan its SP barcode. The engine automatically closes the previous room block and opens the new location without losing data.
  4. Filter & Audit Scans: Tap Duplicates, Locations, or Assets on the single-row filter bar to inspect the session. Use ↩ Undo to revert the last read.
  5. Dispatch ENNX: Review the live preview panel and click ✉ Email ENNX File. The system packages the submission and dispatches it to configured facility recipients.

4-Color Status Row Reference

StatusBadge ColorBorder / HighlightDescription
Asset Asset 4px Green Left Border Valid equipment asset added to the current room location block.
Location Location 4px Blue Left Border Room barcode (SP...) scanned; starts a new room section in the ENNX file.
Duplicate Duplicate 4px Orange Left Border Asset already recorded in the active room; skipped to prevent duplicate ENNX entries.
Ignored Ignored 4px Pink Left Border Pure EPC hex reads or malformed strings; discarded to prevent data corruption.

Output Specification

The system compiles standard VA-compliant ENNX plain-text format:

ENNX
ID
SP009-BD. 8A
517 EE35607
517 EE31883
SP015-BD. 8A
517 EE45001
***END***^5

The trailer ***END***^N calculates N as the exact count of locations and assets, ensuring rejection-free intake into Vista/AEMS-MERS.

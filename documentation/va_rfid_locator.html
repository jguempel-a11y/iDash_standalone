📡 RFID Asset Locator

Database Connected Mobile RFID Optimized Active v2.1 (09/2026)

The RFID Asset Locator is a dedicated tool for locating specific missing assets using an RFID handheld reader. Unlike the VA Site Inventory (which sweeps an entire room), this tool helps you hunt for specific targets that are not where they should be. It features a high-speed scanner engine (30–50 tags/sec), a Geiger counter-style proximity radar meter, dynamic Web Audio pitch feedback, front-of-grid zero-scroll mobile status indicators, and a responsive mobile-optimized UI.

07/25/2026 — Tag Matching Bug Fixes & Raw Read Debug Log

Resolved a silent failure where RFID reads were received correctly but no assets were matched. Root cause: AssetWorx stores rfidtag values with F-padding appended for word alignment (e.g., 512EE17360FFF), and the comparison was not stripping this padding before comparing. Additionally, the SQL lookup did not handle the space/no-space variant of EE numbers (e.g., 512 EE17360 vs 512EE17360).

ChangeDetail
Fix: F-padding strip All tag values (from the reader and from the rfidtag column) are now normalized by stripping trailing F characters before comparison. This matches normalization used in va_eil_live_scan.aspx.
Fix: EE-number fuzzy match Third matching strategy added: if both the scanned tag and the stored rfidtag contain the same numeric EE portion (extracted via regex /EE\s*(\d+)/i), they are considered a match.
Fix: Space-agnostic SQL lookup The LookupAssets WebMethod SQL now also compares REPLACE(a.name, ' ', '') = @idNoSpace and REPLACE(a.rfidtag, ' ', '') = @idNoSpace, so entering 512 EE17360 finds assets stored as 512EE17360 and vice versa.
New: Raw Read Debug Log A Raw Read Log panel (enabled via “Show Raw Read Log” checkbox) records every scan: exact raw string from reader, normalized form used for matching, and whether a match was found.
ℹ Quick Diagnostic: If reads are happening (Total Reads increments) but nothing turns green — enable the Raw Read Log, scan the tag, then compare the Norm: value shown to the RFID Tag column value in the results grid.

07/24/2026 — Initial Release

New dedicated asset locator page with proximity meter, audio feedback, WebSerial USB support, and query-string pre-loading.

Why This Tool Exists

  • Inventory = verification: “Walk this room and confirm what is here.”
  • Locator = hunting: “I have a list of missing items — help me find them.”

Inspired by the RFID WayFinder feature in the AssetWorx Data Dashboard, this iDash version adds proximity metering, audio feedback, WebSerial USB support, and pre-loading from other pages.

How to Use It — Step by Step (User Guide)

Step 1: Enter Target Assets

In the Target Assets panel, type or paste asset identifiers — one per line, comma-separated, or tab-separated (Excel paste). Accepted formats: 512 EE17360, 512EE17360, barcode, serial number, or rfidtag value. Both space and no-space EE formats are recognized.

Step 2: Load & Resolve

Click 🔍 Load & Resolve. On mobile devices, the target drawer automatically collapses into a slim badge (e.g. 2 loaded) to grant maximum screen height to the Geiger radar and target grid. The database populates the target grid with the following columns:

#ColumnPurposeMobile Visibility
1#Row sequence indexFixed left column
2StatusReal-time status badge (✔ FOUND, ◯ SEARCHING, ⚠ NO RFID)Column 2: Instant zero-scroll visibility on mobile
3Asset TagEE number with inline discovery checkmark (✔) and green highlightVisible without scrolling
4Description / ModelEquipment name and model descriptionVisible on swipe / wider screens
5LocationLast recorded facility room / location in AssetWorxPrioritized ahead of RFID tag
6RFID TagStored RFID tag hex string (with F-padding)Secondary technical identifier
7EIL / CMRAccountability grouping codeReference data

If an asset has no recorded tag in AssetWorx, it displays ⚠ NO RFID.

Step 3: Pull Trigger or Focus

The visible high-speed scanner card (#raw) is permanently active and auto-focuses on trigger pull. On a Zebra TC53/TC58 or MC3300R handheld, simply pull the RFID sled trigger to start sweeping.

Step 4: Walk, Sweep & Locate

Walk the facility area while holding the trigger. As target tags enter antenna range:

  • Zero Horizontal Scrolling: The Status column in Column 2 immediately turns emerald green showing ✔ FOUND (just now) — fully visible on narrow 360px–412px handheld screens.
  • Inline Asset Tag Checkmark: An inline green ✔ checkmark badge lights up directly next to the asset identifier with bright green text.
  • High-Contrast Left Accent: The row highlights with a solid 6px emerald green left margin (#10b981) for instant peripheral confirmation.
  • Geiger Proximity Radar: The proximity bar climbs from red → yellow → green → blue as you approach the physical asset.
  • Synthesizer Audio Feedback: Variable pitch Geiger clicks accelerate as signal strength peaks, concluding with a celebratory discovery chime on first detection.

Step 5: Review & Reset

Counts in the top filter bar update automatically (All Targets, Found, Remaining, Unresolved). Click ↺ Reset Found to begin a new search sweep on the same targets, or 🗑 Clear All to load new assets.

LookupAssets WebMethod

[WebMethod] public static object LookupAssets(string[] identifiers)

SQL WHERE clause searches these columns for each identifier:

  • name = @id — exact EE number (e.g., 512 EE17360)
  • rfidtag = @id — stored RFID tag value
  • text12 = @id — barcode
  • text3 = @id — serial number
  • REPLACE(name, ' ', '') = @idNoSpace — space-stripped EE (e.g., 512EE17360)
  • REPLACE(rfidtag, ' ', '') = @idNoSpace — space-stripped rfidtag

Response JSON per asset:

{ input, assetId, name, rfidtag, serial, eil, barcode, location, site, found:false }

rfidtag Field Format

The rfidtag column stores a formatted string, NOT raw EPC hex. Import formula:

rfidtag = CONCAT(station, 'EE', assetNumber,
    REPLICATE('F', 4 - ((5 + LEN(assetNumber)) % 4)))

Example: asset 512 EE17360 → rfidtag = 512EE17360FF. A Zebra reader in DataWedge RFID mode outputs exactly this string.

⚠ If the Raw Read Log shows long hex strings like E2801160600002141D4A5B2F, DataWedge is outputting raw EPC. Reconfigure DataWedge to decode RFID user memory to ASCII.

Tag Matching Logic (Updated 07/25/2026)

// Normalize: strip trailing F-padding, uppercase, trim
function normalizeTag(s) { return s.replace(/F+$/i, '').toUpperCase().trim(); }

// Extract EE number from any format
function extractEENumber(s) { var m = s.match(/EE\s*(\d+)/i); return m ? m[1] : null; }

var tag  = normalizeTag(rawScan);    // "512EE17360"
var rfid = normalizeTag(dbRfidTag);  // "512EE17360"

var isMatch =
    rfid === tag                                           // 1) Exact
    || (tag.length > 4 && (tag.includes(rfid)
                           || rfid.includes(tag)))         // 2) Substring
    || (extractEENumber(tag) === extractEENumber(rfid));   // 3) Same EE#

Raw Read Debug Log (Developer Notes)

Module-level debugLog[] array (max 20, newest-first). Populated by addDebugEntry(raw, normalized, matched) inside processRead() only when #chkDebug is checked. Fully client-side. Cleared by clearAll().

Proximity Calculation

var recent = timestamps.filter(t => (Date.now() - t) < 3000);
var rps = recent.length / 3;              // reads per second, 3-sec window
var pct = Math.min(100, Math.round((rps / 10) * 100));  // 0-10 rps = 0-100%

Bar decays by 5% every 300ms on no reads.

Troubleshooting

“No RFID tag” shown for an asset

The rfidtag column is empty. Asset must be physically tagged and the value recorded in the DB.

Asset not found by Load & Resolve

  • Try both 512 EE17360 and 512EE17360 — both are now supported.
  • Run SELECT name, rfidtag FROM dbo.asset WHERE name LIKE '%17360%' to confirm the asset exists.

RFID Tag column shows a value but nothing matches during scanning

  1. Enable the Raw Read Log checkbox.
  2. Start scanning and point reader at the tagged asset.
  3. Compare Norm: in the log against the RFID Tag column in the grid.
  4. If Norm shows a long hex string (EPC), reconfigure DataWedge to output decoded RFID user memory.
  5. If Norm shows a different EE number than expected, the physical tag does not match the asset entered.

Total Reads counter stays at 0

  • Click Start Scanning first — the pulsing banner must be visible.
  • DataWedge: verify RFID profile is active. Scan capture textarea auto-focuses every 500ms.
  • WebSerial: status must show “Connected” in green.

Audio not playing

  • Click Start Scanning first (satisfies browser user-gesture requirement).
  • Verify the 🔊 Audio Feedback toggle is green.

WebSerial shows “Not Available”

Requires HTTPS or localhost. DataWedge keystroke mode continues to work regardless.

Proximity meter not moving

  • Only activates on target tag reads. Non-target reads do not affect the meter.
  • Reader must be in continuous/inventory mode, not single-read.
  • Requires at least 2 reads to calculate RPS.

📈 Tag Statistics (va_tag_stats.aspx)

The Tag Statistics dashboard is the executive-level tagging performance center for the VA iDash platform. It provides real-time KPI cards, per-site filtering, drill-down panels for specific asset populations, and exportable reports to support leadership's understanding of tagging progress and asset value across all facility stations.

API Driven (JSON) Database Connected Updated 2026-07-21

1. Executive Summary KPI Cards

The top of the page displays five animated KPI cards that update dynamically whenever a different site is selected from the dropdown:

KPI CardData SourceNotes
Total Tagged text18 = '1' Total assets with a physical tag applied
Tagged & In Use text18='1' AND listvalue1 LIKE '%In Use%' Active, in-service tagged assets
Tagged, Not In Use text18='1' AND listvalue1 NOT LIKE '%In Use%' Tagged but out-of-service (disposed, turned in, etc.)
No CMR Assigned text18='1' AND (text8 IS NULL OR text8='') Tagged assets missing EIL/CMR assignment
Value — Not In Use text18='1' AND listvalue1 NOT LIKE '%In Use%' AND text15 IS NOT NULL Sum of text15 (asset dollar value) for tagged, not-in-use assets. Added 2026-04-13.

2. Asset Value KPI & Export

ⓘ Added 2026-04-13
The fifth KPI card and its companion export button were added to surface dollar-value data for leadership reporting on tagged, not-in-use asset populations.

The fifth KPI card displays the total dollar value of all tagged, not-in-use assets for the selected site. The value is sourced from the text15 field in dbo.asset, which was populated via a bulk import from VA-provided xlsx cost files (one per site: 512, 517, 540, 581, 613, 688).

Scope

Only assets matching this filter are included:

text18 = '1'
AND listvalue1 NOT LIKE '%In Use%'
AND text15 IS NOT NULL
AND ISNUMERIC(text15) = 1

Assets with no cost data are excluded from the total.

Export

Clicking the KPI card (or the Asset Value Excel toolbar button) downloads a UTF-8 BOM CSV with the following columns:

ColumnSource
Tag Numberasset.name
Descriptionasset.description
CMR/EILasset.text8
Locationasset.text6
Statusasset.listvalue1
Tag Typeasset.text19
Asset Value ($)asset.text15

A summary footer at the bottom of the export shows the total asset count and the grand total dollar value. The export is handled server-side by the exportassetvalue API route in va_tag_stats.aspx.cs.

3. Asset Value Data Population

Asset values were imported from VA-provided xlsx files using a PowerShell script that read each file via .NET ZIP/XML streaming (no Excel COM required). The script matched on the asset name field (column A = entry_number) and wrote the dollar value to text15 (column S = total_asset_value) for matching records only. Records with literal NULL or non-numeric values were skipped.

4. Tabs & Drill-Down Panels

📊 Executive Summary

KPI cards + site selector. All five cards update on site change.

👤 Employee Activity

Inventory activity by employee ID with today, weekly, monthly, and total counts. Filterable by employee name.

🏷 Tag Type Analysis

Two-panel layout. Left side: clickable tag type counts table — click any row to instantly load the asset preview on the right. Right side: asset preview (Top 100) with column toggle pills — show/hide and drag-to-reorder columns (Asset Tag, Tag Type, Location, Last Observed). Includes per-column filters and sort indicators. A blue badge shows the currently selected tag type.

📋 Site Detail

Tagging detail by Site / CMR / Location with column toggle pills — show/hide and drag-to-reorder columns (Site, CMR/EIL, Location, Tagged, Untagged, Total, % Tagged). Includes per-column filters, sort direction indicators, and progress bars for tagging percentage.

5. Technical Operation

API Pattern

On load or site change, JavaScript calls va_tag_stats.aspx?api=execstats&site=X, which returns a JSON object with all five KPI values. The frontend animates the values using animDollar() for the value card and animNum() for integer cards.

Export Implementation

🛠 ThreadAbortException Fix
The exportassetvalue route streams a UTF-8 BOM CSV directly to the browser using Response.Flush() + Response.Close() (no Response.End()) to avoid the ThreadAbortException issue that previously caused {"error":"Thread was being aborted."} to appear at the end of exported files.

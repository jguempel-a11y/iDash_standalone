Core Capabilities: Everyday Tools for the Field

Wave-and-Walk Room Audits
  • Sweep a handheld RFID reader across a room; items populate on screen in real time.
  • Verified assets turn green, missing items stay highlighted, and misplaced items flag immediately.
  • Completes full room inventories in under 60 seconds.
Acoustic Geiger Counter Locator
  • Enter any asset tag or description to initiate targeted tracking.
  • On-screen signal strength meter paired with audio beeps that speed up as you approach.
  • Finds items concealed behind drywall, above ceiling tiles, or inside closed cabinets.
Offline Field Scanning (Batch Mode)
  • Built for basements, radiology suites, and RF-shielded rooms without Wi-Fi.
  • Crews keep scanning without connection drops or app errors.
  • Automatically syncs and reconciles with the master database once back in coverage.
Browser-Based RFID Label Printing
  • Encode and print EPC Gen 2 smart labels directly from your web browser.
  • Print from search results, location lists, or Excel spreadsheet import batches.
  • Live visual label preview eliminates print errors without needing dedicated print workstations.
Customizable Views & Excel Reports
  • Users pick the exact columns they need (Serial Number, Model, Description, Location, Tag ID).
  • Column choices and filters save automatically for future sessions.
  • One-click export produces clean, supervisor-ready Excel workbooks.
Automated Portal & Chokepoint Tracking
  • Connects to fixed RFID portal readers at loading docks and department entrances.
  • Automatically logs timestamped asset transit events without manual scanning.
  • Detects unauthorized equipment movement between facility areas.

Why Your IT Team Will Appreciate It

  • Zero Client Software: Pure browser-native HTML5, CSS, and JavaScript. Runs on Microsoft Edge, Google Chrome, and Zebra mobile browsers. Nothing to package, push, or patch on workstations.
  • Standard Microsoft Stack: Deploys on standard Microsoft Windows Server IIS and ASP.NET. Fits cleanly into existing agency and military hosting environments.
  • Non-Blocking Database Access: Connects directly to the existing iDash SQL Server database using non-blocking read isolation (READ UNCOMMITTED). Analytical queries and searches will never lock active tables or degrade database performance.
  • Strictly On-Premises Boundary: 100% of data and application logic resides within your internal network. Zero external cloud dependencies, zero third-party analytics, and zero outbound internet requirements.
  • Standard Hardware Protocols: Compatible with standard EPC Class 1 Gen 2 UHF RFID readers, Zebra DataWedge, standard network label printers (Zebra, SATO), and MQTT sensor messaging.

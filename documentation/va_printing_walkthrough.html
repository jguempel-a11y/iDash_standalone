🖨 Printing Guide: Excel Equipment Import & Print

Step-by-step walkthrough for importing equipment data from an Excel file into iDash and printing RFID asset labels — from login to label output.

Prerequisites: Your iDash account must have access to the Excel Equipment Import & Print tile. Contact your administrator if you don't see it on your dashboard. You'll also need a properly formatted .xlsx equipment file.
📋 Steps in This Guide
  1. Sign In to iDash
  2. Navigate to the Hub Dashboard
  3. Find the Excel Equipment Import Tile
  4. Load Your Equipment Data
  5. Review Equipment Data Grid
  6. Select Rows to Import/Print
  7. Choose a Label Template
  8. Configure Site Override & Name Prefix
  9. Import & Print
1 Sign In to iDash
Open your web browser and navigate to the iDash portal URL (e.g. http://your-server/iDash/). You'll see the Intelligent Distributed Asset Scanning Hub login screen. Enter your iDash username and password, then click Sign In.
The iDash login screen — enter your credentials and click Sign In
💡 Tip: If you see "Contact your administrator if you need an account", ask your iDash admin to create an account for you with access to the Excel Print tile.
2 Navigate to the Hub Dashboard
After signing in, you'll land on the Intelligent Distributed Asset Scanning Hub — your main dashboard. This shows all the tiles and tools available to your account. You'll see category tabs at the top: Favorites, Guides & Downloads, Scanning & Tools, and Reports.
The iDash Hub showing your available tiles and categories (logged in as idashadmin)
3 Find the Excel Equipment Import Tile
Click the 📚 Scanning & Tools category tab to reveal the scanning and import tools. Look for the 📚 Excel Equipment Import & Print tile — it has an orange border and describes bulk equipment loading. Click the tile to open the import page.
The Scanning & Tools section showing the Excel Equipment Import tile
4 Load Your Equipment Data
The Excel Import page has two ways to load data:
  • 📁 Auto-Detect (Default) — Automatically reads C:\va_rfid\excel_data\equipment.xlsx if the file exists on the server. A green dot indicates the file was found.
  • 📂 Browse File — Click Choose File to browse your local computer or network share for any .xlsx file, then click 📄 Load File to upload it.
The Excel Import page with file source options, toolbar, and equipment data grid
💡 Tip: The active file source is highlighted with a colored border. If you upload a file, it stays active for your entire session — refreshing the page won't lose it.
5 Review the Equipment Data Grid
Once data is loaded, the Equipment Data tab shows all rows from your Excel file in a scrollable grid. Each row displays: Entry #, Manufacturer, Equipment Name, Model, Serial #, Category, Use Status, Location, Station, and more. The Status column shows:
  • NEW — This asset doesn't exist in iDash yet
  • UPDATE — This asset already exists and will be updated
The data grid showing equipment rows loaded from the Excel file
6 Select Rows to Import/Print
Check the boxes next to the rows you want to process. You can:
  • Click individual row checkboxes to select specific items
  • Click Select All to check every row
  • Click Clear to uncheck all
  • Use the header checkbox to toggle all at once
The counter in the toolbar updates to show "X of Y rows selected".
Select rows using checkboxes — they turn blue when active
7 Choose a Label Template
Use the Template dropdown to select which label format to print. Templates are pre-configured in the Template Mapping Config and correspond to BarTender .btw template files. Common options include:
  • 517_iDash_Std_Small — Standard small RFID label for Site 517 Beckley
  • iDash_Std_Small — Standard small RFID label for other assigned sites (e.g. [512 Baltimore], [540 Clarksburg], [581 Huntington], [613 Martinsburg])
  • Each template shows its assigned site in brackets (e.g. [517 Beckley])
The Template dropdown showing available label formats and their assigned sites
8 Configure Site Override & Name Prefix
Before importing, you can optionally configure:
  • Site Override — Forces all selected rows to a specific company/site (such as 517 Beckley) regardless of the Station # column in the Excel file. Leave on Auto to use the Station column.
  • Name Prefix — Inserts a text prefix before the Entry # when generating asset names (e.g. entering EE turns entry 80886 into 517 Beckley EE80886).
Use the 🔍 Preview Names tab to see exactly what asset names will be generated before importing. Names update instantly as you change the Site Override or Name Prefix.
💡 Tip: Assets are upserted on Asset Name + Site. If a computed name already exists for the chosen site, the existing asset is updated (not duplicated).
9 Import & Print
When you're ready, choose your action:
  • Import Only — Adds/updates assets in iDash without printing any labels
  • Import & Print (green button) — Imports the assets AND queues RFID label print jobs via MQTT to BarTender
A confirmation dialog will appear showing how many rows will be processed. Click OK to proceed. After completion, you'll see a success message with a count of assets created, updated, and print jobs queued.
⚠ Important: For Import & Print to work, the BarTender print server must be running and connected via MQTT. If you see "Print Client not connected", check the Print Administration guide.

🔧 Troubleshooting

Issue Solution
Can't see the Excel Import tile Ask your admin to add excel_print to your tile access in User Management
"Cannot read equipment.xlsx" error Either place the file in C:\va_rfid\excel_data\ or use the Browse File option to upload directly
No label templates in dropdown Templates are configured in Template Mapping Config — at least one must be set up
Import works but no labels print Check that the MQTT print server is connected. See MQTT Configuration
All rows show as UPDATE These assets already exist in iDash. Importing will update their fields. This is normal for re-imports.
"Print Client not connected" error The BarTender print spooler is not running. Start the Run_Bypass_Spooler.ps1 script or check Task Scheduler.

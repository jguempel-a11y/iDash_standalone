    + − Filters  
    Global Filter & Case

    The Global Text filter is for all column data, and defaults to any substring match ('INCLUDES'). But users can refine the search by using the prefix and suffix options listed below. Case sensitivity is also supported with the [Aa] checkbox. Global and column searches can be combined to create a complex "AND" data filter result.

    • Prefix with = to perform an Exact Match of each column field value.
    • Prefix with ^ to perform a BEGINS with Match of each column field value.
    • Sufix with ^ to perform an ENDS with Match of each column field value.
    • Use ! BEFORE the previous options to perform a NOT Match of each column field value.

    Overview of Toolkit:

    This AssetWorx support page allows editing of AssetWorx data in different ways. The Inventory and Scan-2-Print tools require that the page be run on a Zebra Android device with barcode and RFID reader connections. The Add-Data tool is intended mainly for Receiving Departments that have daily responsibilities for printing new RFID tracking tags, and inputting these new assets into the AssetWorx database. Expand the sections below to learn more of what can be accomplished.

    Inventory Tools

    These are tools for performing Initial and Periodic Room Inventory scans, and locating missing items using RFID handheld readers.

    Scan-2-Print is used for initial room barcode scans of legacy asset labels. These scans validate expected room assets, and allow the user to identify an appropriate RFID tag size to use for each item scanned. A "NOTES" field is available to document data discrepencies with the actual tagged part. The tool also auto-updates the AssetWorx database for unexpected assets and locations.

    After completion of each room scan and update to the AssetWorx database, a print tags button appears, allowing the user to send tag print jobs to each tag size printer.

    Finally, this tool also tracks progress of the initial tagging process by maintaining a status log for each asset as ['Scanned', 'Printed', 'Tagged', 'NRF' (no record found)].

    Room Inventory can be used as an alternative to the AssetWorx Android Mobile app. Unlike the current AssetWorx mobile app, this tool generates a new status option of 'Missing' for all unfound items during a room inventory. This allows the 'WayFinder' feature to be used more efficiently for a group of tags.

    Adding Data to AssetWorx

    This API tool is primarily intended to support the needs of Receiving departments that need to add newly acquired assets to the AssetWorx database AND to print and attach new RFID tags to those new products. The same process can be use to add fixed RFID readers, AssetWorx users, custom alarms, and importing other data such as 'Maintenace Date updates' from external software programs like Nuvolo.

    Dashboard Usage Videos

    ID Integration provides this software extension as a more useful data analysis dashboard for the AssetWorx! Tracking Software package. It is a responsive web app, allowing it to be used on any browser enabled device without hardware or OS restrictions. This tool also provides custom data output reports, and a reference for setup and operation of all related hardware and software elements. This browser dashboard can be either installed as a local fileset, or as an IIS web service.

    The API Dashboard has the following advantages over the standard AssetWorx Dashboard.

    1. Easier Data Column Organization - Naming, Order, Visibility
    2. Better Data Filter Options - combine global, column, and location filters
    3. Calendar Date Filtering Options
    4. Easier Data Report Export - Auto Cut/Paste, FileSave, and Email options
    5. Personalized Configuration - Set user default preferences via browser cookies
    6. Asset Location Mapping - via imported floorplan images

    Dashboard Installation:

    It is important to recognize that this Data Dashboard tool is NOT an executable software application. It is simply a collection of text files (html, css, javascript) that can be located anywhere on a PC, but always viewed within a web browser. More commonly, these files are loaded onto a web server such as IIS, so that everyone on your network can benefit from the tool without requiring separate software installations.

    Because this Dashboard is built using the AssetWorx API, it can be highly customized for each AssetWorx deployment. Contact ID Integration to schedule an online session where we can assist you with the configuration setup for your data environment, using your vocabulary, and your data preferences.
